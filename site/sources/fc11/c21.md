21.1.A Moduli for Enriques surfaces. The fixed point free involution $j$ on the K3 surface $X$ induces an involution $j ^ { * }$ on $H ^ { 2 } ( X , \mathbb { Z } )$ which can be described abstractly, using a properly chosen isometry $H ^ { 2 } ( X , \mathbb { Z } ) \ \simeq \Lambda$ . To explain this, we rewrite the K3 lattice as $\Lambda = U \oplus W \oplus W ^ { \prime }$ , where $W , W ^ { \prime }$ are copies of the Enriques lattice. This last decomposition can be used to define the lattice Enriques involution $$ \iota _ { \mathsf { E n r } } ( u , v , v ^ { \prime } ) = ( - u , v ^ { \prime } , v ) , \quad ( u , v , v ^ { \prime } ) \in U \oplus W \oplus W ^ { \prime } . $$
