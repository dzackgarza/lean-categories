### Remark 1.1.5 {#fc11-c01-u015}

::: {.unit-meta}
`FC11-C01-U015` · Chapter 1, source L458 · [not formalized]{.route-unmatched}
:::

Remark 1.1.5. The technique used in the proof of the preceding proposition shows that every quadratic form in characteristic different from 2 is diagonalizable; if there is a non-zero radical, say of dimension $n$ , all diagonalized forms have precisely $n$ zeros on the diagonal. If $k$ is a field of characteristic 2, this is no longer true. Consider for example the so-called hyperbolic plane over $k$ , $U = k \cdot e \oplus k \cdot f$ with bilinear form given by $b ( e , e ) = b ( f , f ) = 0$ , $b ( e , f ) = 1$ . Since $b ( x , x ) = 0$ for all $x \in U$ , this form is not diagonalizable.

::: {.unit-lean}
**Not formalized.** Degenerate diagonalization is available. The characteristic-two hyperbolic example is defined and proved alternating/nonzero, but its non-diagonalizability and the complete nullity comparison are not packaged by the inspected counterexample theorem (which instead disproves injectivity of polarization).
:::

### Definition / construction / notation {#fc11-c01-u016}

::: {.unit-meta}
`FC11-C01-U016` · Chapter 1, source L460 · [not formalized]{.route-unmatched}
:::

Finally a word about the comparison of forms. A metric linear map between two $k$ -vector spaces $V , V ^ { \prime }$ equipped with symmetric bilinear forms, say $( V , b )$ and $( V ^ { \prime } , b ^ { \prime } )$ , is a linear map $f$ for which $b ^ { \prime } ( f ( x ) , f ( y ) ) = b ( x , y )$ for all $x , y \in V$ . If $b$ is non-degenerate, $f$ is injective. If, moreover, $f$ is bijective, then $b ^ { \prime }$ is also nondegenerate and $f$ is called an isometry. Two inner product spaces are said to be isometric if there exists an isometry between them.

::: {.unit-lean}
**Not formalized.** Form-preserving linear maps and categorical isomorphisms exist. This bundled paragraph additionally proves injectivity from nondegeneracy of the source and transfers nondegeneracy through a bijection; the map constructor alone is not that result.
:::

### Remark 1.2.6 {#fc11-c01-u031}

::: {.unit-meta}
`FC11-C01-U031` · Chapter 1, source L521-L523 · after [`FC11-C01-U002`](#fc11-c01-u002), [`FC11-C01-U004`](#fc11-c01-u004) · [not formalized]{.route-unmatched}
:::

Remark 1.2.6. If $B = ( b _ { i j } )$ is a real symmetric matrix of size $n \times n$ , there is a corresponding symmetric form $b ( x , y )$ defined by $\textstyle \sum _ { i , j = 1 } ^ { n } b _ { i j } x _ { i } y _ { j }$ . Note that $b ( x , x ) =$ $\textstyle \sum _ { i , j = 1 } ^ { n } b _ { i j } x _ { i } x _ { j }$ has integral values on $\oplus ^ { n } \mathbb { Z }$ precisely if $b _ { i i } \in \mathbb { Z }$ , $2 b _ { i j } \in \mathbb { Z }$ if $i \neq j$ . Unfortunately, $\operatorname* { d e t } B$ then need not be integral. For instance the matrix $\left( { \begin{array} { l l } { 1 } & { { \frac { 1 } { 2 } } } \\ { { \frac { 1 } { 2 } } } & { 1 } \end{array} } \right)$ having determinant $3 / 4$ would then represent the quadratic form $x ^ { 2 } + x y + y ^ { 2 }$ . In cases where a matrix will be used to define an integral lattice, we shall therefore adhere to Kneser’s convention from [122], i.e., as in formula (1.1) a quadratic form $\begin{array} { r } { ( x _ { 1 } , \ldots , x _ { n } ) \mapsto \sum _ { 1 \leq i \leq j \leq n } q _ { i j } x _ { i } x _ { j } } \end{array}$ corresponds to the upper triangular matrix $Q \ : = \ : ( q _ { i j } )$ and conversely. Then the quadratic form is integral if and only if $Q$ has integral entries and its polar form corresponds to $B = Q + Q ^ { \mathsf { T } }$ , a form with even integral entries on the diagonal and with $\operatorname* { d e t } B$ integral. Thus $x ^ { 2 } + x y + y ^ { 2 }$ corresponds to a polar form with Gram matrix $\left( \begin{array} { c c } { { 2 } } & { { 1 } } \\ { { 1 } } & { { 2 } } \end{array} \right)$ . One could also consider quadratic forms $\textstyle \sum _ { i , j = 1 } ^ { n } q _ { i j } x _ { i } x _ { j }$ , starting from a symmetric integral matrix ( $q _ { i j }$ ). J.W. Cassels [36] calls such forms classically integral after Gauß. However, this excludes forms like $x ^ { 2 } + x y + y ^ { 2 }$ .

::: {.unit-lean}
**Not formalized.** The whole unit includes triangular coefficient conventions, polar matrix Q+transpose Q, half-integral versus classically integral forms and the specified binary example. Generic symmetric Gram constructors do not cover this bundle.
:::
