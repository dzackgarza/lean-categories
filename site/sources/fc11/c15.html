Proposition 15.1.1

Proposition 15.1.1. Let ?? be a non-degenerate symmetric (respectively quadratic) lattice, \(S\) a primitive non-degenerate sublattice and \(T = S ^ { \perp }\) . With the notation of diagram (15.1), the following equivalent properties hold: 1. on \(\mathsf { H } _ { S } \subset \mathsf { d g } _ { S }\) the glueing criterion \(b _ { T } ^ { \# } ( \psi _ { S , T } - , \psi _ { S , T } - ) + b _ { S } ^ { \# } ( - , - ) = 0\) , respectively \(q _ { T } ^ { \# } \ L { \circ } \psi _ { S , T } + q _ { S } ^ { \# } = 0\) holds; 2. up to a sign the embedding \(\psi _ { S , T }\) is an isometry of torsion forms; 3. \(\mathsf { H } : = g r a p h\) of \(\psi _ { S , T } \subset \mathrm { d g } _ { S } \oplus \mathrm { d g } _ { T }\) is an isotropic subspace. If ?? is unimodular, then \(\mathsf { H } _ { S } = \mathsf { d } \mathrm { g } _ { S }\) , \(\psi _ { S , T }\) is an isomorphism and the glueing condition becomes \(b _ { S } ^ { \# } \simeq - b _ { T } ^ { \# }\) (respectively \(q _ { S } ^ { \# } \simeq - q _ { T } ^ { \# } ,\) .

Example / comparison

FC11-C15-U002 · Chapter 15, source L7611 · after FC11-C15-U001

Example 15.1.2. An example illustrating Proposition 15.1.1 is the following. Let \(L = U \mathbb { \ Q } U\) be the sum of two copies of the hyperbolic plane \(U\) , the first one with the usual basis \(e , f\) (so \(b ( e , e ) = b ( f , f ) = b ( e , f ) - 1 = 0 ,\) ) and the second one with similar basis \(e ^ { \prime } , f ^ { \prime }\) . Take \(S\) to be the span of \(e + f , e ^ { \prime } + f ^ { \prime }\) in \(L\) , and let \(T\) be the span of \(e - f , e ^ { \prime } - f ^ { \prime }\) in \(L\) . Then \(L\) is an even unimodular overlattice of \(S \textsuperscript { \textregistered T }\) . The discriminant groups of \(S\) and \(T\) are \(\begin{array} { r } { \mathrm { d } \mathrm { g } _ { S } = \frac { 1 } { 2 } S / S = \langle u = \frac { 1 } { 2 } ( e + f ) + S , u ^ { \prime } = \frac { 1 } { 2 } ( e ^ { \prime } + f ^ { \prime } ) + S \rangle } \end{array}\) and \(\begin{array} { r } { \mathrm { d } \mathrm { g } _ { T } = \frac { 1 } { 2 } T / T = \langle v = \frac { 1 } { 2 } ( e - f ) + T , v ^ { \prime } = \frac { 1 } { 2 } ( e ^ { \prime } - f ^ { \prime } ) + T \rangle } \end{array}\) . The image of \(L / ( S \mathbb { Q } T )\) in \(\mathsf { d g } _ { S } \oplus \mathsf { d g } _ { T }\) equals \(\left\{ 0 , ( u , v ) , ( u ^ { \prime } , v ^ { \prime } ) , ( u + u ^ { \prime } , v + v ^ { \prime } ) \right\}\) , which is the graph of the isomorphism \(\psi _ { S , T } : \mathrm { d g } _ { S } \mathrm { d g } _ { T }\) determined by \(\psi _ { S , T } ( u ) = v\) and \(\psi _ { S , T } ( u ^ { \prime } ) = v ^ { \prime }\) . Note that \(\begin{array} { r } { b _ { S } ^ { \# } ( u , u ) = \frac { 1 } { 2 } + \mathbb { Z } = - b _ { T } ^ { \# } ( v , v ) } \end{array}\) , etc. Also, for the associated quadratic form \(\begin{array} { r } { q ( x ) = \frac { 1 } { 2 } b ( x , x ) } \end{array}\) we have \(\begin{array} { r } { q _ { S } ^ { \# } ( u ) = \frac { 1 } { 2 } \cdot \frac { 1 } { 2 } + \mathbb { Z } = \frac { 1 } { 4 } + \mathbb { Z } } \end{array}\) and \(\begin{array} { r } { q _ { T } ^ { \# } ( v ) = \frac { 1 } { 2 } \cdot - \frac { 1 } { 2 } + \mathbb { Z } = - \frac { 1 } { 4 } + \mathbb { Z } } \end{array}\) , etc.

Proposition 15.1.3

FC11-C15-U003 · Chapter 15, source L7615-L7622

Proposition 15.1.3. Let \(S\) and \(T\) be non-degenerate symmetric (respectively quadratic) lattices, \(\mathsf { H } _ { S } \subset \mathsf { d g } _ { S }\) a subgroup, and \(\psi _ { S , T } : { \mathsf { H } } _ { S } \hookrightarrow { \mathsf { d g } } _ { T }\) an injective homomorphism. Suppose that the glueing criterion of Proposition (15.1.1) holds. Then, setting \(N : = S \textcircled { \perp } T\) , we have 1. The lattice \(L = \{ y \in N ^ { * } \mid y\) mod \(N \in \mathsf { H }\) }, where \(\mathsf { H }\) is the graph of \(\psi _ { S , T }\) , is \(a\) symmetric (respectively quadratic) overlattice of \(N\) satisfying \([ L : N ] = | \mathsf { H } _ { S } |\) ; 2. ?? and \(T\) embed primitively in \(L\) and \(T = S ^ { \perp }\) , \(S = T ^ { \perp }\) ; 3. If \(\mathsf { H } _ { S } = \mathsf { d } \mathrm { g } _ { S }\) and \(\psi _ { S , T }\) is an isomorphism, then \(L\) is unimodular.

Corollary 15.1.4

FC11-C15-U004 · Chapter 15, source L7629-L7630

Corollary 15.1.4. Let \(L\) be a non-degenerate even lattice with one isometry class in its genus and suppose that the non-degenerate lattice \(S\) embeds primitively in \(L\) . Then any lattice \(S ^ { \prime }\) in the same genus as \(S\) embeds primitively in \(L\) .

Example / comparison

FC11-C15-U005 · Chapter 15, source L7633 · after FC11-C01-U052, FC11-C02-U014, FC11-C15-U004

Example 15.1.5. Here is an example of two non-isometric lattices in the same genus that embed in the same even unimodular lattice. The lattices \(E _ { 8 } \ @ E _ { 8 }\) and \(\Gamma _ { 1 6 }\) are in the same genus, but are not isometric (see Examples 1.5.1 and 11.3.2). The indefinite unimodular lattices \(\{ \Phi ^ { k } U \ @ E _ { 8 } \ @ E _ { 8 }\) and \(\mathbb { \oplus } ^ { k } U \mathbb { \oplus } \Gamma _ { 1 6 }\) , \(k = 1 , 2 , \ldots\) , however, are both even and have the same signature, and so are isometric by Theorem 2.4.1. Note that Corollary 15.1.4 applies in this case, but is not needed.

Proposition 15.1.6

FC11-C15-U006 · Chapter 15, source L7637-L7649

Proposition 15.1.6 (Extending isometries, II). Let \(S , S ^ { \prime } , T , T ^ { \prime }\) be non-degenerate quadratic lattices related by isometries \(\sigma : S \stackrel { \sim } { \to } S ^ { \prime }\) and \(\tau : T \stackrel { \sim } { } T ^ { \prime }\) . Suppose \(L\) , \(L ^ { \prime }\) are quadratic overlattices of \(S \oplus T\) , \(S ^ { \prime } \mathcal { \text O T } ^ { \prime }\) , respectively. Assume that \(S\) and \(T\) are primitively embedded in \(L\) , and similarly for \(S ^ { \prime }\) and \(T ^ { \prime }\) . Then the isometry \(\lambda = \sigma \oplus \tau\) extends to an isometry \(L \stackrel { \sim } { } L ^ { \prime }\) if and only if (the map induced by) \(\lambda\) sends the subgroup \(L / ( S \mathbb { Q } T )\) of \(\mathsf { d g } _ { S } \mathbb { O } \mathsf { d g } _ { T }\) to the subgroup \(L ^ { \prime } / ( S ^ { \prime } \mathbb { \oplus } T ^ { \prime } )\) of \(\mathsf { d g } _ { S ^ { \prime } } \mathbb { O } \mathsf { d g } _ { T ^ { \prime } }\) . In other words, using the notation of diagram (15.1), \(\lambda\) extends if and only if there is a commutative diagram \[ \begin{array} { r l } { \mathrm { d } \mathrm { g } _ { S } \longleftrightarrow } & { { } \longleftrightarrow \mathsf { H } _ { S } \longleftrightarrow \quad \quad \psi _ { S , T } \quad \quad \mathrm { ~ } \mathsf { \Gamma } \lambda } \\ { r _ { S , S ^ { \prime } } ( \sigma ) \underset { \mathrm { d } \mathrm { g } _ { S ^ { \prime } } \longleftrightarrow } { \downarrow } } & { { } \underset { H _ { S ^ { \prime } } \longleftrightarrow } { \downarrow } \underbrace { \vphantom { \sqrt { \Gamma _ { T , T ^ { \prime } } ( \tau ) } } \mathrm { d } r _ { T , T ^ { \prime } } ( \tau ) } } & { { } \mathrm { ~ } \forall r _ { T , T ^ { \prime } } ( \tau ) } \end{array} \] where \(r _ { S , S ^ { \prime } } ( \sigma )\) and \(r _ { T , T ^ { \prime } } ( \tau )\) are induced by \(\sigma\) and \(\tau\) , respectively. In particular, if \(L\) (and hence \(L ^ { \prime }\) ) is unimodular, using Propositions 15.1.1, 15.1.3, this reduces to the glueing criterion exhibited by the commutative diagram \[ \begin{array} { r l } { \mathrm { d g } _ { S } \cfrac { \simeq } { \psi _ { S , T } } } & { \to \mathrm { d g } _ { T } } \\ { r _ { S , S ^ { \prime } } ( \sigma ) \sqrt { \qquad } } & { \sqrt { r _ { T , T ^ { \prime } } ( \tau ) } } \\ { \mathrm { d g } _ { S ^ { \prime } } \cfrac { \simeq } { \psi _ { S ^ { \prime } , T ^ { \prime } } } } & { \to \mathrm { d g } _ { T ^ { \prime } } } \end{array} \]

Theorem 15.1.7

FC11-C15-U007 · Chapter 15, source L7653-L7656

Theorem 15.1.7 (Witt’s extension theorem for lattices). 1. Let \(L\) be a nondegenerate even lattice and let \(i , i ^ { \prime } : S \hookrightarrow L\) be two primitive embeddings. Then these embeddings are equivalent if and only if an isometry \(T = i ( S ) ^ { \perp } \stackrel { \sim } { \to } T ^ { \prime } = i ^ { \prime } ( S ) ^ { \perp }\) exists inducing a commutative diagram like (15.2). 2. Suppose in addition that \(L\) is unimodular, then two primitive embeddings of ?? in \(L\) with isometric orthogonal complements are equivalent if the reduction homomorphism \(r _ { T } : { \cal O } ( T ) \to { \cal O } ( q _ { T } ^ { \# } )\) is surjective, where \(T\) is the orthogonal complement of an embedded copy of \(S\) .

Theorem 15.2.3

FC11-C15-U010 · Chapter 15, source L7694-L7703

Theorem 15.2.3 (Universal Embeddability). Let \(( r _ { + } , r _ { - } )\) be a pair of non-negative integers for which \(r _ { + } { - } r _ { - } \equiv 0\) mod 8 and let \(( s _ { + } , s _ { - } )\) be a pair of non-negative integers with \(s _ { + } \leq r _ { + }\) and \(s _ { - } \leq r _ { - }\) . Then every even non-degenerate lattice \(S\) of signature \(( s _ { + } , s _ { - } )\) satisfing \(r _ { + } + r _ { - } -\) \(\operatorname { r a n k } ( S ) \geq \ell ( \mathsf { d g } _ { S } )\) can be primitively embedded in some even unimodular lattice \(L\) of signature \(( r _ { + } , r _ { - } )\) if \[ s _ { + } + s _ { - } \leq \frac 1 2 \mathrm { r a n k } ( L ) . \] In case \(r _ { + } > 0\) and \(r _ { - } > 0\) , the unimodular lattice \(L\) is unique up to isometry.

Lemma 15.2.4
