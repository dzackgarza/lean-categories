Definition / construction / notation

FC11-C18-U001 · Chapter 18, source L8839

In practice \(L\) is often the lattice associated to a generalized Dynkin diagram \(\Gamma\) . However, in general the roots corresponding to the vertices of \(\Gamma\) do not define a vanishing lattice. Theorem 18.1.7 provides a large class of Dynkin diagrams that do not suffer from this defect. As demonstrated in Section 18.2, these can be used to determine the monodromy group of many singularities.

Definition / construction / notation

FC11-C18-U002 · Chapter 18, source L8845

In this section \(( L , q )\) is a quadratic integral lattice with polarization \(^ { b }\) . By ”root” we shall mean ” \(\left( - 2 \right)\) -root” and accordingly we set \(\epsilon = -\) . With appropriate changes all results are valid for 2-roots and \(\epsilon = +\) . The set of roots in \(L\) is denoted \(\Delta ( L )\) , the lattice generated by these \(L _ { \mathrm { r o o t } }\) , and the Weyl group \({ \mathsf { W } } ^ { - } ( L )\) .

Definition / construction / notation

FC11-C18-U003 · Chapter 18, source L8847

The lattices we consider in this chapter are spanned by roots which form the nodes of a graph. If \(r , r ^ { \prime }\) are such roots and \(b ( \boldsymbol { r } , \boldsymbol { r } ^ { \prime } ) = 1\) , as usual, we connect the corresponding nodes by an unlabelled edge. In the lattices also pairs \(\{ r , r ^ { \prime } \}\) occur for which \(b ( r , r ^ { \prime } ) = - 2\) . We connect the corresponding nodes by a doubly dashed edge. The resulting graphs \(\Gamma\) are called (generalized) Dynkin diagrams and the corresponding even integral lattice \(L _ { \Gamma }\) they give rise to the associated rootlattice. Identifying the vertices of \(\Gamma\) with roots in \(L _ { \Gamma }\) , the Weyl group \({ \mathsf { W } } ^ { - } ( { \Gamma } )\) of \(\Gamma\) is the group generated by the reflections determined by \(\Gamma\) .

Lemma 18.1.1

FC11-C18-U006 · Chapter 18, source L8857-L8858

Lemma 18.1.1. Two roots in a 1-connected component of a set of roots \(\Delta \subset L = L _ { \Gamma }\) belong to the same \({ \mathsf { W } } ^ { - } ( \Delta )\) -orbit.

Definition 18.1.2

FC11-C18-U007 · Chapter 18, source L8863-L8865

Definition 18.1.2. 1. A vanishing lattice consists of a pair \(( L , \Delta )\) of a lattice \(L\) and a set of roots \(\Delta\) spanning \(L\) and forming a single orbit under \(W ^ { - } ( \Delta ) =\) \(\langle \sigma _ { r } \rangle _ { r \in \Delta }\) , that is \(\Delta = \Delta\) . 2. A vanishing lattice \(( L , \Delta )\) contains the vanishing lattice \(( L ^ { \prime } , \Delta ^ { \prime } )\) if \(L ^ { \prime }\) is a primitive sublattice of \(L\) and \(\Delta ^ { \prime } \subset \Delta\) .

Remark 18.1.3

FC11-C18-U008 · Chapter 18, source L8867 · after FC11-C18-U006, FC11-C18-U007

Remark 18.1.3. The vertices of a generalized Dynkin diagram \(\Gamma\) form a finite set of roots, say \(\Delta\) , spanning the lattice \(L _ { \Gamma } = \mathbb { Z } \cdot \Delta\) . If \(\Delta\) is 1-connected, by Lemma 18.1.1 all roots in \(\Delta\) are in the same orbit under the reflection group \({ \mathsf { W } } ^ { - } ( \Delta )\) , but \(\Delta\) need not be an entire orbit. Taking \(\Delta = \mathsf { W } ^ { - } ( \Delta )\) instead of \(\Delta\) then yields a vanishing lattice. In general, if the subset \(\Delta\) of roots of \(L\) belongs to a single \({ \mathsf { W } } ^ { - } ( \Delta )\) -orbit, this procedure yields a vanishing lattice. Clearly, this also shows that such a vanishing lattice is determined by the lattice itself.

Theorem 18.1.7

FC11-C18-U017 · Chapter 18, source L8906-L8915 · after FC11-C18-U007, FC11-C18-U014

Theorem 18.1.7 ([60, Thm 3]). Let \(( L , q )\) be a quadratic lattice of rank at least 4 containing a special subset Λ of roots which span \(L\) . Then \(( L , \pmb { \Lambda } )\) is a vanishing lattice. If, moreover, \(L\) splits off an extra hyperbolic plane besides the socle plane, then \(\mathsf { W } ^ { - } ( L ) = \mathsf { W } ^ { - } ( \Lambda )\) . More precisely, we have: 1. • Let \(U\) be the socle plane and \(L = U \mathbb { \textcircled { 1 } L ^ { \prime } }\) the corresponding socle decomposition. Then \(L ^ { \prime }\) is spanned by \(\Lambda ^ { \prime } = \Lambda - \{ r _ { 1 } , r _ { 2 } \}\) . • Conversely, let \(L\) be a quadratic lattice of rank at least 4 with a decomposition \(L = U \oplus L ^ { \prime }\) , where \(L ^ { \prime }\) is spanned by a 1-connected set of roots \(\Lambda ^ { \prime }\) . Let \(\{ e , f \}\) be the standard basis of \(U\) and \(r _ { 3 } \in \Lambda ^ { \prime }\) . Then the set of roots \(r _ { 1 } = e - f , r _ { 2 } = - e + r _ { 3 } , r _ { 3 } , r \in \Lambda ^ { \prime }\) forms a special subset of roots. 2. With \(\Lambda ^ { \prime }\) as in \(\mathit { 1 }\) , the roots \(r ^ { \prime } \in \Lambda ^ { \prime }\) belong to the same \(\mathsf { W } ^ { - } ( L ^ { \prime } )\) -orbit. 3. \(\psi _ { U } L ^ { \prime } \subset \mathsf { W } ^ { - } ( \Lambda )\) 4. If, moreover, \(L ^ { \prime } = U ^ { \prime } \oplus L ^ { \prime \prime }\) for some hyperbolic plane \(U ^ { \prime }\) , then \(W ^ { - } ( \Lambda ) \ =\) \({ \mathsf { W } } ^ { - } ( L )\) . In other words, the Weyl group of \(L\) is generated by the reflections \(\sigma _ { r }\) , where the roots \(r\) belong to \(\Lambda\) .
