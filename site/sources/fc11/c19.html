Definition / construction / notation

FC11-C19-U001 · Chapter 19, source L9253

Proposition 19.1.1

FC11-C19-U002 · Chapter 19, source L9259-L9263

Proposition 19.1.1. All K3 surfaces \(X\) are K¨ahler and are mutually diffeomorphic. The Betti numbers are \(b _ { 1 } ( X ) = b _ { 3 } ( X ) = 0\) , \(b _ { 2 } ( X ) ~ = ~ 2 2\) , and the Hodge numbers are \(h ^ { 1 , 0 } ( X ) = h ^ { 0 , 1 } ( X ) = 0\) , \(h ^ { 2 , 0 } ( X ) = 1\) and \(h ^ { 1 , 1 } ( X ) = 2 0\) . The intersection lattice \(H ^ { 2 } ( X , \mathbb { Z } )\) is isometric to the \(K \mathcal { 3 }\) -lattice \[ \Lambda : = U ^ { \oplus 3 } \oplus E _ { 8 } ( - 1 ) ^ { \oplus 2 } . \]

If ?? is irreducible, then \(D \cdot D \geq - 2\) and if equality holds \(D\) is a nodal curve, that is, a smooth rational curve. 3. ?? is ample if and only if \(D \cdot D > 0\) and \(D \cdot D ^ { \prime } > 0\) for all nodal curves \(D ^ { \prime }\) .

Definition / construction / notation

FC11-C19-U004 · Chapter 19, source L9275-L9279

For brevity, the classes of effective, respectively ample divisors in the N´eron– Severi lattice \(\mathsf { N S } ( X )\) are called effective, respectively ample classes. Likewise, the class of a nodal curve is called a nodal class. Observe that nodal classes are roots in \(\mathsf { N S } ( X )\) , but not conversely. In fact, \(\left( - 2 \right)\) -roots in the N´eron–Severi lattice are classes of divisors \(D\) with \(D \cdot D = - 2\) which are not necessarily effective or irreducible. Reflections in \(\left( - 2 \right)\) -roots in \(\mathsf { N S } ( X )\) generate its Weyl group. Since the corresponding hyperplane reflections extend to \(H ^ { 2 } ( X , \mathbb { Z } )\) , this group can be considered as a subgroup of \(\mathsf { O } ( H ^ { 2 } ( X , \mathbb { Z } ) )\) . We call it the Weyl group of \(X\) : \[ \mathsf { W } ^ { - } ( X ) : = \mathsf { W } ^ { - } ( \mathsf { N S } ( X ) ) \subset \mathsf { O } ( H ^ { 2 } ( X , \mathbb { Z } ) ) . \]

Construction / comparison

FC11-C19-U005 · Chapter 19, source L9281

The Weyl group of a K3 surface is a normal subgroup of the orthogonal group of its integral second cohomology.

Definition / construction

FC11-C19-U006 · Chapter 19, source L9283-L9287

The roots in the Néron–Severi lattice of a K3 surface have a canonical partition \(\Delta(NS(X))=\Delta_X^+\sqcup(-\Delta_X^+)\), where \(\Delta_X^+\) is the set of effective roots.

Definition / construction / notation

FC11-C19-U007 · Chapter 19, source L9289

The Hodge index theorem B.2.3 states that the intersection product on \(H _ { \mathbb { R } } ^ { 1 , 1 } ( X ) =\) \(H ^ { 1 , 1 } ( X ) \cap H ^ { 2 } ( X , \mathbb { R } )\) has signature \(( 1 , h ^ { 1 , 1 } ( X ) - 1 )\) , and so it gives \(H _ { \mathbb { R } } ^ { 1 , 1 } ( X )\) the structure of a hyperbolic vector space containing \(\mathsf { N S } ( X )\) . As explained in Appendix B.2, there is a preferred component \(\complement _ { X }\) of the “light cone” \(\{ x \in H _ { \mathbb { R } } ^ { 1 , 1 } ( X ) \mid x \cdot x > 0 \}\) , namely the one that contains the K¨ahler classes and which is called the positive cone. The group \(\mathsf { W } ^ { - } ( X )\) acts on \(H _ { \mathbb { R } } ^ { 1 , 1 } ( X )\) and by (16.3) it preserves the positive cone.

Definition / construction

FC11-C19-U008 · Chapter 19, source L9291-L9299 · after FC11-C19-U004

The Kähler cone of a K3 surface is the subcone of the positive cone consisting of classes pairing positively with every nodal class.

Definition / construction

FC11-C19-U009 · Chapter 19, source L9301-L9305 · after FC11-C19-U008

For a projective K3 surface, the cone spanned by ample classes is the intersection of the Kähler cone with \(NS(X)\otimes\mathbf R\).

Definition / construction / notation

FC11-C19-U010 · Chapter 19, source L9307 · after FC11-C19-U009

This cone is called the ample cone of \(X\) . The ample classes are precisely the integral classes of the ample cone.

Proposition 19.1.3

FC11-C19-U011 · Chapter 19, source L9309-L9316 · after FC11-C19-U004, FC11-C19-U008, FC11-C19-U010

Proposition 19.1.3. 1. The closure of the K¨ahler cone is a fundamental domain for the action of the Weyl group \(\mathsf { W } ^ { - } ( X )\) (cf. (19.1)) on \(C _ { X }\) . 2. If \(X\) is projective, the closure of the ample cone is a fundamental domain for the action of the Weyl group \({ \mathsf { W } } ^ { - } ( X )\) on the intersection of the positive cone with \({ \mathsf { N S } } ( X ) \otimes \mathbb { R }\) . 3. The set of nodal classes determines the K¨ahler cone and if \(X\) is projective, these nodal classes determine the ample cone. 4. The choice of a K¨ahler class determines the entire K¨ahler cone and in the projective case, the choice of an ample class determines the entire ample cone.

Theorem 19.2.1

FC11-C19-U012 · Chapter 19, source L9333-L9335

Theorem 19.2.1. 1. Two \(K \mathcal { 3 }\) -surfaces are isomorphic if and only if there are markings such that the corresponding period points are the same (”injectivity of the period map” – or – ”Torelli theorem”). 2. All points of the period domain are period points (”surjectivity of the period map”).

Corollary 19.2.3

Corollary 19.2.3. An isometry of \(H ^ { 2 } ( X , \mathbb { Z } )\) preserving the Hodge decomposition is, up to sign and (left or right) multiplication with an element of \(\mathsf { W } ^ { - } ( X )\) , induced by a unique automorphism of \(X\) .

Lemma 19.2.4

Lemma 19.2.4. For a \(K \mathcal { 3 }\) surface \(X\) there is an injection \[ \operatorname { A u t } ( X ) \hookrightarrow \operatorname { O } ( H ^ { 2 } ( X , \mathbb { Z } ) ) , \quad g \mapsto g ^ { * } . \]

Lemma 19.2.5

FC11-C19-U017 · Chapter 19, source L9367

Lemma 19.2.5. The marked \(K \mathcal { 3 }\) -surfaces \(( X , \varphi )\) , \(( X , \pm \varphi \circ w )\) , \(w \in \mathsf { W } ^ { - } ( X )\) and \(( X , \varphi \circ g ^ { * } )\) , \(g \in \operatorname { A u t } ( X )\) , all have the same period point. Let us draw a further consequence of Theorem 19.2.1 which addresses general behaviour . We say that a property holds generally on some complex variety if it holds on the complement of countably many proper subvarieties. In this sense the general K3 surface is not algebraic, for instance the Kummer surface constructed from a non-algebraic complex two-torus is not algebraic. Theorem 19.2.1 implies that more is true:

Corollary 19.2.7

FC11-C19-U020 · Chapter 19, source L9373-L9374

Corollary 19.2.7. The general \(K \mathcal { 3 }\) surface does not have any curves on it, in other words, its Picard number, i.e., the rank of its N´eron–Severi lattice, is zero.

Definition 19.2.9

FC11-C19-U024 · Chapter 19, source L9399

Definition 19.2.9. Suppose that \(S\) is a non-degenerate lattice which is either negative definite or has signature \(( 1 , r _ { - } )\) , \(r _ { - } \ge 0\) , and which is primitively embedded in \(\Lambda\) . A marking \(\varphi : H ^ { 2 } ( X , \mathbb { Z } ) \stackrel { \sim } { \to } \Lambda\) such that \(S \subset \varphi ( { \mathsf { N S } } ( X ) )\) is called an \(S\) -marking. The pair \(( X , \varphi )\) with \(\varphi\) an \(S\) -marking is called an \(S\) -marked \(\mathbf { \Delta } \mathbf { K } \mathbf { \mathcal { 3 } }\) surface. 3

Definition / construction

FC11-C19-U025 · Chapter 19, source L9401-L9407

For a primitively embedded lattice \(S\subset\Lambda\), the period domain \(D(S^\perp)=\{[u]\in D(\Lambda):u\cdot S=0\}\) parametrizes \(S\)-marked K3 surfaces; it has dimension \(20-\operatorname{rank}S\), and outside a countable hyperplane arrangement the Néron–Severi lattice is exactly the marked copy of \(S\).

Proposition 19.2.10

FC11-C19-U026 · Chapter 19, source L9411-L9413

Proposition 19.2.10 ([158, §2]). 1. Every non-degenerate negative definite quadratic lattice \(S\) of rank \(\rho \leq 1 1\) or of signature \(( 1 , \rho - 1 )\) , \(1 \leq \rho \leq 1 0\) , occurs as the N´eron–Severi lattice of a general \(S\) -marked \(K \mathcal { 3 }\) surface and embeds uniquely in the K3 lattice. 2. Proposition 19.2.11

FC11-C19-U027 · Chapter 19, source L9417-L9421

Proposition 19.2.11 ([158, Cor. 2.9, Cor. 2.10]). Let \(X\) be a K3 surface. 1. If \(1 2 \leq \rho ( X ) \leq 2 0\) , then the N´eron–Severi lattice of \(X\) is unique in its genus. 2. If \(\rho ( X ) \leq 1 0\) , then the transcendental lattice of \(X\) is unique in its genus.

Remark 19.2.12

FC11-C19-U028 · Chapter 19, source L9424-L9426 · after FC11-C01-U053, FC11-C02-U014, FC11-C15-U014

Remark 19.2.12. 1. In the non-algebraic situation \(\mathsf { N S } ( X )\) can indeed be negative definite or have a one-dimensional null-space. The last two cases occur if and only if the function field of \(X\) has transcendence degree \(a ( X ) = 0\) , respectively \(a ( X ) = 1\) . Indeed, if an isotropic \(f \in \mathsf { N S } ( X )\) exists, then \(\pm f\) is effective and one can show (cf. [124, Thm. 4.1,4.2]) that a suitable multiple defines an elliptic fibration. This implies that \(a ( X ) \geq 1\) . If \(a ( X ) = 2\) the surface \(X\) is algebraic (cf. [15, Ch. IV. Corollary 6.5]) and its N´eron–Severi lattice is not negative semi-definite. If \(\mathsf { N S } ( X )\) is negative definite, \(X\) cannot be elliptic or algebraic, and hence \(a ( X ) = 0\) . 2. By Theorem 15.2.6 any unimodular lattice \(S\) of rank \(\leq 2 0\) embeds uniquely in the K3 lattice provided \(T = S ^ { \perp }\) is indefinite. This ceases to be true if \(T\) is definite which may only occur in the non-algebraic situation. The simplest example is presented by the sublattice \(S = \mathbb { O } ^ { 3 } U\) . In the standard embedding its orthogonal complement is \(\mathbb { O } ^ { 2 } E _ { 8 } ( - 1 )\) . However, as we have seen (Example 1.5.1.2), there is another even unimodular rank 16 lattice which is negative definite and indecomposable, \(\Gamma _ { 1 6 } ( - 1 )\) . By Theorem 2.4.1, which gives the classification of indefinite even unimodular lattices, \(\Phi ^ { 3 } U \oplus \oplus ^ { 2 } E _ { 8 } ( - 1 ) \simeq \oplus ^ { 3 } U \oplus \Gamma _ { 1 6 } ( - 1 )\) . So two possible period domains then occur for (non-algebraic) K3 surfaces having the same N´eron–Severi lattice, but with different transcendental lattices.
