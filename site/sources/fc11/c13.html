FC11 — Peters & Sterk, Symmetric and Quadratic Forms.

This chapter contains 11 definitions, 1 theorem, 4 propositions, 3 lemmas, 1 corollary, 6 examples, 4 constructions, 3 remarks and 1 convention.

Nobody has checked this chapter against Lean yet, so the statements below say nothing about whether they are formalized.

Definition / construction / notation

FC11-C13-U001 · Chapter 13, source L6707

The spin group of a quadratic vector space \(( V , q )\) over a field \(k\) is defined by means of its Clifford algebra \({ \mathsf { C } } ( q )\) . As a vector space this is just the exterior algebra \(\Lambda ( V )\) and it contains \(V\) . The algebra structure comes from \(q\) . For us its importance lies in the action of the algebra conjugation. Firstly, conjugation with a non-isotropic vector \(u \in V\) preserves \(V\) and, secondly, in \(V\) this gives the hyperplane reflection \(\sigma _ { u }\) up to a sign. This property for \(u\) can be extended to a ”large” subgroup of \({ \mathsf { C } } ( q )\) . To do this properly, one makes use of a canonical splitting of \({ \mathsf { C } } ( q )\) into even and odd elements. The even elements form a subalgebra, the even Clifford algebra. The conjugation with \(u\) receives a sign according to whether \(u\) is odd or even. The Clifford group consists of the invertible elements \(u\) of the Clifford algebra which have the property that twisted conjugation with \(u\) preserves \(V\) .

Definition 13.1.1

FC11-C13-U002 · Chapter 13, source L6739

Definition 13.1.1. The Clifford algebra \({ \mathsf { C } } ( q )\) is defined as the quotient of the tensor algebra \(T ( V )\) on \(V\) by the two-sided ideal \(I ( q )\) generated by \(x \otimes x - q ( x ) \cdot { \bf 1 }\) , \(x \in V\) , and with multiplication induced by the multiplication in \(T ( V )\) . We denote the multiplication in the Clifford algebra by a dot.

Definition / construction

FC11-C13-U003 · Chapter 13, source L6741-L6747 · after FC11-C13-U002

The quotient construction of the Clifford algebra carries a canonical linear map \(\iota:V\to\mathsf C(q)\) with \(\iota(x)^2=q(x)1\); this map is injective, and \(V\) is hence identified with its image in \(\mathsf C(q)\).

Definition / construction

FC11-C13-U004 · Chapter 13, source L6749 · after FC11-C13-U002

Equivalently, the Clifford algebra is characterized by the universal property that every linear map \(u:V\to A\) into a unital algebra with \(u(x)^2=q(x)1\) extends uniquely to an algebra homomorphism \(\mathsf C(q)\to A\).

Definition / construction

FC11-C13-U005 · Chapter 13, source L6751-L6763 · after FC11-C13-U002

The Clifford algebra has a canonical \(\mathbf Z/2\mathbf Z\)-grading \(\mathsf C(q)=\mathsf C^0(q)\oplus\mathsf C^1(q)\). The grading involution \(\alpha\) is \(+1\) on the even Clifford algebra and \(-1\) on the odd part.

Construction / comparison

FC11-C13-U006 · Chapter 13, source L6765

The tensor-degree filtration descends to \(\mathsf C(q)\) and its associated graded algebra is canonically isomorphic to the exterior algebra \(\Lambda V\).

Example / comparison

FC11-C13-U008 · Chapter 13, source L6771-L6773 · after FC11-C13-U002

Hamiltonian quaternions revisited. Consider the standard diagonal form \(x _ { 1 } ^ { 2 } + x _ { 2 } ^ { 2 } + x _ { 3 } ^ { 2 }\) on \(\mathbb { R } ^ { 3 }\) . Its Clifford algebra has as a vector space basis \(\{ 1 , e _ { 1 } , e _ { 2 } , e _ { 3 } , i = e _ { 2 } e _ { 3 } , j = e _ { 3 } e _ { 1 } , k = e _ { 2 } e _ { 1 } , e _ { 1 } e _ { 2 } e _ { 3 } \}\) , where \(\{ e _ { 1 } , e _ { 2 } , e _ { 3 } \}\) is the standard basis of \(\mathbb { R } ^ { 3 }\) . Since for \(i , j = 1 , 2 , 3\) we have \(e _ { i } e _ { j } = - e _ { j } e _ { i }\) for \(i \neq j\) , and \(e _ { i } ^ { 2 } = 1\) , it follows that \(\pmb { i } \cdot \pmb { j } = e _ { 2 } e _ { 3 } e _ { 3 } e _ { 1 } = e _ { 2 } e _ { 1 } = \pmb { k }\) and similarly for the cyclic permutations of \(i , j , k\) . Moreover, \(\pmb { i } ^ { 2 } = \pmb { j } ^ { 2 } = \pmb { k } ^ { 2 } = - 1\) . So the vector space with basis \(\{ 1 , \pmb { i } , \pmb { j } , \pmb { k } \}\) generates the algebra of the Hamilton quaternions \(\mathbb { H }\) which we already encountered in \(\ S\) 5.4.A. This is the even Clifford algebra for the dot product form on \(\mathbb { R } ^ { 3 }\) . As a special case of the second example below we shall see that \(\mathbb { H }\) also figures as the full Clifford algebra of the form \(- x _ { 1 } ^ { 2 } - x _ { 2 } ^ { 2 }\) on \(\mathbb { R } ^ { 2 }\) . Recall also that we explained in Section 5.4 how to associate a ternary quadratic form to any quaternion algebra \(\begin{array} { r } { D = \left( \frac { a , b } { k } \right) } \end{array}\) , namely the norm form restricted to the subspace \({ \cal D } ^ { ( 0 ) }\) of the quaternions of trace \(0\) . For the Hamilton quaternions this is the dot product form on \(\mathbb { R } ^ { 3 }\) where \(\mathbb { R } ^ { 3 }\) is identified with the real space with basis \(\{ \dot { \pmb { i } } , \dot { \pmb { j } } , \pmb { k } \}\) , the so-called pure quaternions. In general the even Clifford algebra of the norm form on \({ \cal D } ^ { ( 0 ) }\) is precisely \(D\) .

FC11-C13-U009 · Chapter 13, source L6775-L6815 · after FC11-C08-U014, FC11-C13-U002

Real Clifford algebras (cf. [68, 179]) By Sylvester’s law 8.1.3 nondegenerate real forms are classified by their signature \(( r , s )\) with representing diagonal quadratic forms \(\textstyle \sum _ { i = 1 } ^ { r } x _ { i } ^ { 2 } - \sum _ { i = r + 1 } ^ { n } x _ { i } ^ { 2 }\) , \(n = r + s\) . The corresponding Clifford algebra \({ \mathsf C } _ { r , s }\) is then generated by the standard basis \(\{ \pmb { e } _ { 1 } , \ldots , \pmb { e } _ { r + s } \}\) subject to the relations \[ \begin{array} { r } { e _ { i } ^ { 2 } = \left\{ \begin{array} { l l } { 1 } & { \mathrm { ~ i f ~ } i \leq r } \\ { - 1 } & { \mathrm { ~ i f ~ } i > r } \end{array} \right. \quad \mathrm { a n d } \quad e _ { i } \cdot e _ { j } + e _ { i } \cdot e _ { j } = 0 \mathrm { ~ i f ~ } i \neq j . } \end{array} \] For example, \({ \mathrm { C } } _ { 0 , 0 } = \mathbb { R }\) , \(\mathrm { C } _ { 1 , 0 } = \mathbb { R } \oplus \mathbb { R }\) , while \({ \mathsf C } _ { 0 , 1 } = \mathbb C\) . We shall now show that the isomorphism class of the Clifford algebra of a real quadratic form does not determine the signature. To do so we make basic use of quadratic forms over \(\mathbb { F } _ { 2 }\) as suggested by the signs that appear in the above relations. We start by considering the group ring \(\mathbb { R } [ G ]\) , \(G = \Pi ^ { n } C _ { 2 }\) . where \(C _ { 2 }\) is the cyclic group of order 2. Viewing \(C _ { 2 }\) as the field \(\mathbb { F } _ { 2 }\) and switching to additive notation and identifying groupelements of \(G\) with vectors \(\pmb { x } \in \mathbb { F } _ { 2 } ^ { n }\) , this group ring becomes the real vector space \(V : = \oplus _ { x \in G } \mathbb { R } \cdot e _ { x }\) with algebra structure induced by the additive group structure, i.e., the product \(^ *\) is given by \(e _ { x } * e _ { y } = e _ { x + y }\) . As vector spaces \(V\) and \({ \mathsf C } _ { r , s }\) are isomorphic: identify \(e _ { x } \in \ V\) with the element \(\pmb { e } _ { i _ { 1 } } \cdot \cdot \cdot \pmb { e } _ { i _ { k } } \in \mathbb { C } _ { r , s }\) where \(_ x\) has \(i\) -th coordinate 1 precisely if \(i \in \{ i _ { 1 } , \ldots , i _ { k } \}\) . In particular, if \(\{ e _ { 1 } , \ldots , e _ { n } \}\) is the standard basis of \(\mathbb { F } _ { 2 }\) , \[ e _ { e _ { k } } { \mathrm { ~ c o r r e s p o n d s ~ t o ~ } } e _ { k } . \] The possibly non-commutative Clifford algebra \({ \mathsf C } _ { r , s }\) comes from the twisted group action \[ e _ { x } \cdot e _ { y } = ( - 1 ) ^ { \beta ^ { r , s } ( x , y ) } e _ { x } * e _ { y } , \] where \(\beta ^ { r , s }\) is the \(\mathbb { F } _ { 2 }\) -valued (in general non-symmetric) bilinear form on \(\mathbb { F } _ { 2 } ^ { n }\) , which in coordinates with respect to the standard basis \(\{ e _ { 1 } , \ldots , e _ { n } \}\) is given by \(x A ^ { r , s } { \bf y } ^ { \scriptscriptstyle 1 }\) , where \(A\) is the upper-triangular matrix \[ A ^ { r , s } = \left( \begin{array} { l l l l } { 0 } & { 1 } & { \cdots } & { 1 } \\ { \vdots } & { 0 } & { \ddots } & { \vdots } \\ { \vdots } & { \ldots } & { \ddots } & { 1 } \\ { 0 } & { \cdots } & { \ldots } & { 0 } \end{array} \right) + \left( \begin{array} { l } { 0 _ { r } } \\ { \phantom { - } } \\ { 0 _ { s \times r } } \end{array} \right| \left( \begin{array} { l } { 0 _ { r \times s } } \\ { \phantom { - } } \\ { \phantom { - } } \\ { 0 _ { s \times r } } \end{array} \right) \] By the correspondence (13.4) the relations \(( - 1 ) ^ { A _ { i j } ^ { r s } } = - 1\) for \(j > i\) and \(( - 1 ) ^ { A _ { i j } ^ { r s } } = 1\) for \(j < i\) imply that the desired anti-commutation relations hold, while \(( - 1 ) ^ { A _ { i i } ^ { r s } } = \mathbf { 1 }\) for \(i \leq r\) and \(( - 1 ) ^ { A _ { i i } ^ { r s } } = - { \bf 1 }\) for \(i > r\) , proving the remaining two relations. Observe that as in equation (1.1) in Chapter 1, a bilinear form defines a unique quadratic form on \(\mathbb { F } _ { 2 } ^ { n }\) . Conversely, given a basis for a \(\mathbb { F } _ { 2 }\) -vector space, a quadratic form \(q\) determines an upper-triangular bilinear form \(\beta\) which can be used to define a twisted product (13.5). The resulting associative algebra is denoted \(C _ { \mathbb { R } } [ \mathbb { F } _ { 2 } ^ { n } , q ]\) . This algebra has a special structure: either the generators \(\mathbf { \boldsymbol { e } } _ { i }\) and \(e _ { j }\) for \(i \neq j\) anticommute (namely if \(\beta _ { i j } = 1\) for \(i < j\) since then \(\pmb { e } _ { i } \cdot \pmb { e } _ { j } = - \pmb { e } _ { i } * \pmb { e } _ { j }\) and \(\pmb { e } _ { j } \cdot \pmb { e } _ { i } = \pmb { e } _ { i } * \pmb { e } _ { j }\) ), or they commute (if \(\beta _ { i j } = 0\) for \(i < j\) , since then \(\pmb { e } _ { i } \cdot \pmb { e } _ { j } = \pmb { e } _ { j } \cdot \pmb { e } _ { i } = \pmb { e } _ { i } * \pmb { e } _ { j }\) ). It follows that isometric forms \(q\) give isomorphic algebras. So the classification of the real Clifford algebras follows from the classification of the quadratic forms on the vector spaces \(\mathbb { F } _ { 2 } ^ { n }\) as given in Example 8.2.7. The nondegenerate forms live on even-dimensional spaces and come in two types depending on the Arf invariant. The ones with zero Arf invariant are the form \(q _ { 0 } = \mathbb { Q } ^ { m } U\) , \(n = 2 m\) , the ones with Arf invariant 1 are of the form \(q _ { 1 } = \Phi ^ { m - 1 } U \odot \Phi ^ { 2 } \langle 1 \rangle\) , \(n = 2 m\) . On odd dimensional spaces, say of dimension \(n = 2 m + 1\) , one has three types with \(\mathrm { d i m } \operatorname { r a d } ( q ) \leq 1\) , namely \(q _ { 0 } ^ { \prime } = \Phi ^ { m } U \circledast 0\) , \(q _ { 1 } ^ { \prime } = \oplus ^ { m - 1 } U \oplus \oplus ^ { 2 } \langle 1 \rangle \oplus 0\) and \(q _ { 2 } = \Phi ^ { m } U \odot\) [1]. We shall show that these types indeed give all the real Clifford algebras \({ \mathsf C } _ { r , s }\) . Note however, to identify \(\mathsf { C } _ { \mathbb { R } } [ \mathbb { F } _ { 2 } ^ { n } , q ]\) with some \({ \mathsf C } _ { r , s }\) , one has to transform each of the 5 types of quadratic forms \(q ( { \pmb x } )\) into the desired shape \(\pmb { x } A ^ { r , s } \pmb { x } ^ { \scriptscriptstyle 1 }\) , where \(A ^ { r , s }\) is as in formula (13.6). This poses no problem for \(\mathsf { C } _ { \mathbb { R } } \left[ \mathbb { F } _ { 2 } ^ { 2 } , q _ { i } \right]\) , \(i \in \{ 0 , 1 \}\) : these are the 4-dimensional Clifford algebras \(\mathrm { C _ { 2 , 0 } , C _ { 0 , 2 } }\) with generators \(\mathbf { \boldsymbol { e } } _ { 1 } , \mathbf { \boldsymbol { e } } _ { 2 }\) subject to \[ \begin{array} { r l } { \pmb { e } _ { 1 } ^ { 2 } = \pmb { e } _ { 2 } ^ { 2 } = 1 , \quad } & { \pmb { e } _ { 1 } \cdot \pmb { e } _ { 2 } = - \pmb { e } _ { 2 } \cdot \pmb { e } _ { 1 } \mathrm { ~ f o r ~ } q _ { 0 } } \\ { \pmb { e } _ { 1 } ^ { 2 } = \pmb { e } _ { 2 } ^ { 2 } = - 1 , \quad } & { \pmb { e } _ { 1 } \cdot \pmb { e } _ { 2 } = - \pmb { e } _ { 2 } \cdot \pmb { e } _ { 1 } \mathrm { ~ f o r ~ } q _ { 1 } . } \end{array} \] Next, since \(x _ { 1 } x _ { 2 } + x _ { 2 } ^ { 2 }\) has Arf invariant \(0\) it is isometric to \(x _ { 1 } x _ { 2 }\) (in fact \(( x _ { 1 } , x _ { 2 } ) \mapsto\) \(\left( x _ { 1 } + x _ { 2 } , x _ { 2 } \right)\) is an isometry). The first corresponds to \(\mathrm { C _ { 1 , 1 } }\) and the second to \(\mathrm { C _ { 2 , 0 } }\) which indeed shows that the Clifford algebra does not determine the signature.
