Lemma 9.1.1

FC11-C09-U001 · Chapter 9, source L5032-L5038

Lemma 9.1.1. The torsion module \(G\) is isomorphic to its dual \(G _ { Q ( R ) / R } ^ { * }\) . Let \[ G \simeq \oplus _ { j = 1 } ^ { r } R / d _ { j } R , \quad d _ { 1 } | d _ { 2 } | \cdot \cdot \cdot | d _ { r } \] be the invariant factor decomposition with corresponding generators \(e _ { 1 } , \ldots , e _ { r }\) . Then the isomorphism \(G \stackrel { \simeq } { \to } G _ { Q ( R ) / R } ^ { * }\) can be chosen such that \(e _ { j }\) maps to the function \(u _ { j } ^ { \ast } \in G _ { Q ( R ) / R } ^ { \ast }\) for which \(u _ { j } ^ { \ast } ( e _ { i } ) = d _ { j } ^ { - 1 } \delta _ { i j } \in Q ( R ) / R\) .

Definition 9.1.2

Proposition 9.2.1

FC11-C09-U010 · Chapter 9, source L5133-L5151

Proposition 9.2.1. 1. Lemma 9.3.1

Example / comparison

Lemma 9.3.3

FC11-C09-U014 · Chapter 9, source L5191-L5194

Lemma 9.3.3. If \(G\) is a homogeneous \(p\) -primary group of exponent \(k\) equipped with a symmetric \(p\) -primary torsion form \(^ { b }\) , then \(( G , b )\) is non-degenerate if and only if \(\rho ( b )\) is. Proposition 9.3.7

Proposition 9.3.7. Definition 9.3.8

FC11-C09-U020 · Chapter 9, source L5271-L5275

Definition 9.3.8. The basic invariants under isometry of a non-degenerate \(p\) -primary symmetric torsion group \(( G , b )\) are: • the number of elementary divisors of \(G\) equal to \(p ^ { k }\) \(=\) the length of \(H _ { k }\) in any Jordan splitting \(G = \mathbb { Q } H _ { k }\) of \(G\) = the rank of \(\rho _ { k } ( G )\) as a \(\mathbb { Z } / p \mathbb { Z }\) -module; • if \(p\) is odd, for each \(k\) as above, \(\mathrm { d i s c } ( \rho _ { k } ( b ) ) \in \mathsf { D } ( \mathbb { F } _ { p } )\) . For \(p\) -primary quadratic torsion groups \(( G , q )\) the invariants are those of the associated polar form \(b _ { q }\) .
