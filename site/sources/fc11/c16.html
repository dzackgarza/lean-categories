Definition / construction / notation

FC11-C16-U027 · Chapter 16, source L8220-L8224

Divisors on tori such as \(J ( C )\) come from holomorphic functions \(f\) on \(\mathbb { C } ^ { g }\) which are quasi-periodic with respect to the lattice \(\Gamma\) defining the torus, that is, for all \(\gamma \in \Gamma\) and \(z \in \mathbb { C } ^ { g }\) , one has \(f ( \pmb { z } + \gamma ) = \varphi _ { \gamma } ( \pmb { z } ) f ( \pmb { z } )\) for some non-vanishing holomorphic function \(\varphi _ { \gamma }\) . The simplest is Riemann’s theta function \(\theta _ { Z }\) , a quasi-periodic function on \(\mathbb { C } ^ { g }\) defined by the everywhere convergent series \[ \theta _ { Z } ( z ) = \sum _ { \pmb { x } \in \mathbb { Z } ^ { g } } \exp 2 \pi i \left[ \pmb { x } \cdot ( \pmb { z } + \frac { 1 } { 2 } Z \pmb { x } ) \right] , \quad \pmb { z } \in \mathbb { C } ^ { g } , \]
