FC11-C02-U001 · Chapter 2, source L1676 · not formalized

Theorem. An indefinite unimodular lattice is uniquely determined by its parity, rank and index.

Not formalized. The project defines parity, signature and unimodularity and supplies standard models, but no theorem classifies every indefinite unimodular integral lattice by parity, rank and index.

Definition 2.1.1

FC11-C02-U002 · Chapter 2, source L1686 · in lean-categories

Definition 2.1.1. Let \(( L , b )\) be an integral lattice and \(p\) a prime number. Its reduction modulo \(p\) consists of the \(\mathbb { F } _ { p }\) -vector space \(L / p L\) equipped with the symmetric \(\mathbb { F } _ { p }\) -bilinear form induced by \(^ { b }\) .

Formalized. LeanCategories/Lattices/Valued/Residue.lean::reduceIntegralToResidueField, reduceIntegralToResidueField_pairing_tmul — For R=Z and the prime ideal (p), the residue-field base change is the canonical reduction of the lattice modulo p and its pairing is the reduction of the integral pairing.

Construction / comparison

FC11-C02-U003 · Chapter 2, source L1688 · not formalized

Reduction of an integral lattice modulo \(p\) can become degenerate; if the original discriminant is prime to \(p\), the reduced bilinear form is non-degenerate and hence gives an inner-product space over \(\mathbf F_p\).

Not formalized. The reduction functor and the generic criterion that a finite bilinear form is nondegenerate iff its determinant is nonzero are available, but no existing declaration connects primality of the integral discriminant to nondegeneracy of this lattice reduction as one theorem.

Lemma 2.1.2

FC11-C02-U004 · Chapter 2, source L1690-L1691 · not formalized

Lemma 2.1.2. Let \(( L , b ) \underline { { \ d } }\) be an even integral lattice with \(\operatorname { d i s c } ( b )\) odd. The inner product space \(V = ( L / 2 L , b )\) has even dimension and the rank of \(L\) is also even.

Not formalized. The ingredients for an alternating reduction in characteristic two are present, but the claimed even-dimensionality/rank theorem for an even odd-discriminant lattice is not an existing declaration.

Remark 2.1.3

FC11-C02-U005 · Chapter 2, source L1694 · not formalized

Remark 2.1.3. An inner product space in characteristic 2 such as \(V\) is a symplectic space. These are treated from a general point of view in Appendix A.5.

Not formalized. Mathlib has alternating bilinear forms and symplectic matrices, but no bundled general symplectic-space owner matching the source remark was identified.

Definition 2.1.4

FC11-C02-U006 · Chapter 2, source L1698 · not formalized

Definition 2.1.4. Let \(L\) be an integral lattice with odd discriminant. We say that \(u \in L\) is a characteristic element if \(u \cdot x \equiv x \cdot x\) mod 2 for every \(x \in L\) .

Not formalized. TauCeti defines characteristic covectors only for plumbing lattices. The source definition quantifies characteristic elements of an arbitrary odd-discriminant integral lattice.

Example / comparison

FC11-C02-U007 · Chapter 2, source L1700 · after FC11-C02-U006 · not formalized

Example 2.1.5. For an even integral lattice with odd discriminant \(x \cdot x\) is even by definition, and so \(u = 0\) is a characteristic element.

Not formalized. Evenness is implemented and TauCeti has plumbing characteristic covectors, but no arbitrary-lattice theorem states that zero is characteristic under the source hypotheses.

Lemma 2.1.6

FC11-C02-U008 · Chapter 2, source L1704-L1711 · after FC11-C02-U006 · not formalized

Lemma 2.1.6. Every lattice \(L\) with odd discriminant has a characteristic element \(u \in L\) . Moreover, its so-called \(\sigma\) -invariant \[ \sigma ( L ) : = u \cdot u { \bmod { 8 } } \] does not depend on the choice of the characteristic element. It is an additive invariant, that is, for all lattices \(L\) and ?? with odd discriminant we have \(\sigma ( L { \textcircled { \pm } } M ) =\) \(\sigma ( L ) + \sigma ( M )\) .

Not formalized. No searched source provides existence of characteristic elements for all odd-discriminant lattices together with well-definedness and orthogonal additivity of the square modulo eight.

Remark 2.1.7

FC11-C02-U009 · Chapter 2, source L1734 · not formalized

Remark 2.1.7. The above concerns only lattices with odd discriminant, the only cases we need later on.

Not formalized. This is a scope remark about the preceding sigma-invariant construction; because that construction is unmatched, there is no independent Lean owner for the remark.

Example / comparison

FC11-C02-U010 · Chapter 2, source L1736-L1738 · after FC11-C02-U006 · not formalized

Example 2.1.8. • Let \(L\) be the symmetric lattice \(L = \oplus ^ { p } \langle 1 \rangle \oplus \oplus ^ { q } \langle - 1 \rangle\) . Since \(\pm e\) is characteristic for the unimodular lattice \(\mathbb { Z } \cdot e\) with \(e \cdot e = \pm 1\) and because of additivity, \(\sigma ( L ) \equiv p - q = \tau ( L )\) mod 8, where, we recall, \(\tau ( L )\) is the index of \(L\) . • For an even lattice the zero vector is a characteristic element and so for even lattices we have \(\sigma ( L ) \equiv 0\) mod 8.

Not formalized. Standard rank-one lattices and evenness exist, but the sigma-invariant calculations modulo eight are not formalized.

Theorem 2.2.1

FC11-C02-U011 · Chapter 2, source L1744-L1745 · not formalized

Theorem 2.2.1 (Classification in rank \(\leq 4\) ). Let \(L\) be a unimodular lattice of rank at most 4. Then either \(L\) is odd and diagonalizable, or, if \(L\) is even, \(L \simeq U\) , or \(L \simeq U \oplus U\) .

Not formalized. The standard hyperbolic lattice and unimodularity/signature predicates exist; the complete rank-at-most-four classification of all unimodular lattices does not.

Corollary 2.2.2

FC11-C02-U012 · Chapter 2, source L1758-L1759 · not formalized

Corollary 2.2.2. Let \(L\) be an indefinite unimodular lattice, then • \(L\) contains an isotropic vector, that is, a non-zero vector \(x\) with \(x \cdot x = 0\) ; • \(L\) is isometric to either \(U \odot L ^ { \prime }\) or to \(W \left( \downarrow \right) L ^ { \prime \prime }\) where \(L ^ { \prime }\) as well as \(L ^ { \prime \prime }\) are unimodular, \(U\) is the hyperbolic plane and \(W = \left. 1 \right. \textcircled { \bullet } \left. - 1 \right.\) .

Not formalized. Generic isotropic-vector and orthogonal-complement tools do not prove that every indefinite unimodular integral lattice contains an integral isotropic vector and splits off U or the odd plane W.

Theorem 2.3.1

FC11-C02-U013 · Chapter 2, source L1768-L1769 · not formalized

Theorem 2.3.1. Every odd indefinite unimodular lattice is diagonalizable, that is, isometric to an orthogonal direct sum of copies of ⟨1⟩ and \(\langle - 1 \rangle\) . In particular, such lattices are classified by their rank and index.

Not formalized. Diagonalization of symmetric forms over fields does not imply integral diagonalization of every odd indefinite unimodular Z-lattice. No integral classification theorem was identified.

Theorem 2.4.1

FC11-C02-U014 · Chapter 2, source L1774-L1775 · not formalized

Theorem 2.4.1. Two even indefinite unimodular lattices with the same rank and index are isometric.

Not formalized. No theorem identifies arbitrary even indefinite unimodular lattices having the same rank and index.

Theorem 2.4.2

FC11-C02-U015 · Chapter 2, source L1782-L1783 · not formalized

Theorem 2.4.2. For every unimodular lattice \(L\) , indefinite or not, we have \(\sigma ( L ) =\) \(\tau ( L )\) mod 8, that is, the index modulo 8 is the \(\sigma\) -invariant. If, moreover, \(L\) is even, the index is divisible by 8.

Not formalized. Signature/index and evenness are represented, but the van der Blij congruence sigma(L)=tau(L) mod 8 and its divisibility consequence are not formalized.

Corollary 2.4.3

FC11-C02-U016 · Chapter 2, source L1788-L1792 · not formalized

Corollary 2.4.3 (Existence and uniqueness for indefinite even unimodular lattices). Let \(L\) be an even unimodular and indefinite lattice of (necessarily even) rank \(r\) and index \(\tau = 8 a \varepsilon\) , where ?? is a non-negative integer and \(\varepsilon = \pm 1\) . Then \(L\) is isometric to \[ \underbrace { ( E _ { 8 } \oplus \cdot \cdot \cdot \oplus E _ { 8 } ) } _ { a \ s u m m a n d s } ( \varepsilon ) \ \textcircled { > } \ \underbrace { U \oplus \cdot \cdot \cdot \oplus U } _ { b \ s u m m a n d s } , \quad b = \frac { 1 } { 2 } ( r - | \tau | ) . \]

Not formalized. E8, the hyperbolic plane and orthogonal-sum constructions exist, but the source row is an existence-and-uniqueness classification for all even indefinite unimodular lattices, which those constructors do not establish.

Example / comparison

FC11-C02-U017 · Chapter 2, source L1794 · not formalized

Example 2.4.4. Applying this to the lattice \(E _ { 8 } \oplus E _ { 8 } ( - 1 )\) a lattice of rank 16 and index \(0\) , we obtain \(E _ { 8 } \oplus E _ { 8 } ( - 1 ) \simeq \oplus ^ { \mathrm { s } } U\) .

Not formalized. The E8 and U models are implemented, but no isometry E8 plus its opposite to eight hyperbolic planes was identified.

Definition / construction / notation

FC11-C02-U018 · Chapter 2, source L1810 · not formalized

For an oriented compact \(4\)-manifold \(X\), the cup/intersection pairing on \(H^2(X,\mathbf Z)/\mathrm{tors}\) is its unimodular symmetric intersection form. A form occurring this way is called topologically, respectively differentiably, realizable.

Not formalized. Mathlib mentions intersection forms only as motivation in manifold bordism, while TauCeti constructs the form of a plumbing graph. Neither constructs the unimodular cup/intersection form on H^2 of an arbitrary oriented compact four-manifold or the realizability notions.

Lemma 2.5.1

FC11-C02-U019 · Chapter 2, source L1814 · not formalized

Lemma 2.5.1. If \(X , X ^ { \prime }\) are two four-manifolds, then we have \(S _ { X \# X ^ { \prime } } = S _ { X } \oplus S _ { X ^ { \prime } }\)

Not formalized. TauCeti proves orthogonal splitting for plumbing blow-ups, not the connected-sum formula for arbitrary four-manifolds.

Construction / comparison

FC11-C02-U020 · Chapter 2, source L1816 · after FC11-C02-U018 · not formalized

For a simply connected four-manifold, the intersection form is torsion-free; when it is indefinite its isometry class is determined by parity and index.

Not formalized. Simply-connected-space and unimodular-lattice APIs do not establish torsion-freeness of H^2 or the indefinite intersection-form classification for four-manifolds.

Theorem 2.5.2

FC11-C02-U021 · Chapter 2, source L1820 · after FC11-C02-U018 · not formalized

Theorem 2.5.2. The oriented homeomorphism type of a simply connected fourmanifold \(X\) is completely determined by \(S _ { X }\) and, moreover, any unimodular form can occur in this way as the intersection form of some simply connected fourmanifold.

Not formalized. No formalization of Freedman classification/existence for simply connected topological four-manifolds was found in project, Mathlib, package, GitHub, or reference searches.

Theorem 2.5.3

FC11-C02-U022 · Chapter 2, source L1827-L1833 · after FC11-C02-U018 · not formalized

Theorem 2.5.3 (Donaldson [54]). If a simply connected differentiable four-manifold \(X\) has a definite intersection form it is diagonalizable over \(\mathbb { Z }\) and so \[ S _ { X } = \langle 1 \rangle \oplus \cdots \oplus \langle 1 \rangle { \mathit { o r } } S _ { X } = \langle - 1 \rangle \oplus \cdots \oplus \langle - 1 \rangle . \] In particular, it cannot be an even form.

Not formalized. Algebraic diagonalization over fields is not Donaldson diagonalization over Z. No compatible formalization of Donaldson theorem was found.

Construction / comparison

FC11-C02-U023 · Chapter 2, source L1835 · after FC11-C02-U018 · not formalized

Donaldson diagonalization together with the indefinite unimodular classification leaves only diagonal forms or orthogonal sums of hyperbolic planes and copies of \(E_8(\pm1)\) as possible intersection forms of smooth simply connected four-manifolds.

Not formalized. The standard U and E8 lattices exist, but the asserted restriction on smooth simply connected four-manifold intersection forms depends on Donaldson and the global integral classification, both unmatched.

Proposition 2.5.4

FC11-C02-U024 · Chapter 2, source L1847-L1848 · not formalized

Proposition 2.5.4 (Criterion for even forms). Let \(X\) be a compact differentiable four-manifold such that \(H ^ { * } ( X , \mathbb { Z } )\) has no 2-torsion. Then \(S _ { X }\) is even if and only if the second Stiefel–Whitney class \(w _ { 2 } ( X )\) vanishes.

Not formalized. No second Stiefel-Whitney class API and no theorem equating its vanishing with parity of the integral intersection form under the no-2-torsion hypothesis was identified.

Example / comparison

FC11-C02-U025 · Chapter 2, source L1863 · after FC11-C02-U018 · not formalized

Example 2.5.5. Let \(X\) be a simply connected four-manifold. For these \(H _ { 1 } ( X , \mathbb { Z } ) =\) 0 and then \(0 = \operatorname { T o r s } ( H _ { 1 } ( X , \mathbb { Z } ) ) = \operatorname { T o r s } ( H ^ { 2 } ( X , \mathbb { Z } ) )\) , by the universal coefficient theorem and Poincar´e duality (cf. for example [86, Ch. 28]). Hence there is no torsion at all in the cohomology. So, if \(w _ { 2 } ( X ) = 0\) , the intersection form is even.
