The ring of integers of \(K\) is defined as \(\mathfrak { D } _ { K } = \{ x \in K \mid p _ { x } ( X ) \in \mathbb { Z } [ X ] \}\) , where \(p _ { x } ( X )\) is the monic minimal polynomial of \(x\) This is a free \(\mathbb { Z }\) -module of rank \(d = d _ { K }\) on which the trace is integer valued and hence the pairing \(( x , y ) \mapsto { \mathsf { T r } } _ { K / \mathbb { Q } } ( x y )\) , \(x , y \in \mathfrak { D } _ { K }\) , is integer valued. In other words, \(( \mathfrak { D } _ { K } , \mathsf { T r } _ { K / \mathbb { Q } } )\) is an integral \(\mathbb { Z }\) -lattice and so its discriminant, discriminant of \(\mathfrak { D } _ { K }\) – denoted \(\mathfrak { d } _ { K }\) – is an integer.

Definition / construction / notation

FC11-C05-U001 · Chapter 5, source L3320-L3324

5.1.A Lattices obtained from codes. A linear code is a linear subspace of \(\mathbb { F } _ { q } ^ { n }\) where \(q = p ^ { s }\) , a power of a prime number \(p\) . If \(p = 2\) the code is called a binary code. A vector \(x\) of a code \(c\) is also called a word . It has weight \[ w ( x ) = \mathrm { n u m b e r ~ o f ~ n o n \mathrm { - } z e r o ~ c o o r d i n a t e s ~ o f } \ x , \quad x = ( x _ { 1 } , \dots , x _ { n } ) \in C \subset \mathbb { F } _ { q } ^ { n } . \]

Definition / construction / notation

FC11-C05-U002 · Chapter 5, source L3326

The dot-product \(x \cdot y \ = \ \sum x _ { j } y _ { j } \ \in \ \mathbb { F } _ { q }\) of two vectors \(x \ : = \ : ( x _ { 1 } , \ldots , x _ { n } )\) and \(y \ =\) \(( y _ { 1 } , \ldots , y _ { n } )\) in \(\mathbb { F } _ { q } ^ { n }\) defines a non-degenerate symmetric bilinear form and a code is called isotropic if \(c\) is an isotropic subspace of \(\mathbb { F } _ { q } ^ { n }\) with respect to the dot-product, i.e., if \(C \subset C ^ { \perp }\) , and self-dual if \(C = C ^ { \perp }\) .

Remark 5.1.1

FC11-C05-U003 · Chapter 5, source L3328

Remark 5.1.1. In Chapter 8 we answer the obvious question: how to place the dotproduct on vector spaces over \(\mathbb { F } _ { 2 }\) in the isometry classification? It turns out that Corollary 8.3.4 implies that in odd characteristic \(b\) is isometric to the dot-product if and only if \(\mathrm { d i s c } ( b ) = 1\) As a consequence of Proposition 8.2.1 if \(p = 2\) the odd form \(^ { b }\) is isometric to the dot-product if and only if \(\mathrm { d i s c } ( b ) = 1\) and \(^ { b }\) is totally anisotropic, i.e., there are no isotropic vectors.

Definition / construction

FC11-C05-U004 · Chapter 5, source L3330-L3350

For a code \(C\subset\mathbf F_p^n\), let \(\rho:\mathbf Z^n\to\mathbf F_p^n\) be reduction modulo \(p\) and equip \(\mathbf Z^n\) with the Euclidean form scaled by \(p^{-1}\). The Construction-A lattice is \(\Gamma_C=\rho^{-1}(C)\subset\mathbf Z^n(p^{-1})\); it is positive definite of rank \(n\) and contains \(p\mathbf Z^n\).

FC11-C05-U005 · Chapter 5, source L3336-L3340

a code \(c\) lifts to a submodule \(\rho ^ { - 1 } C\) of \(\mathbb { Z } ^ { n }\) which contains the submodule \(p \cdot \mathbb { Z } ^ { n } =\) \(\rho ^ { - 1 } ( 0 )\) and hence is of finite index in \(\mathbb { Z } ^ { n }\) . It inherits the structure of a lattice from \(\mathbb { Z } ^ { n }\) equipped with its dot-product. However, it turns out to be more convenient to use a different lattice structure, namely \(\mathbb { Z } ^ { n }\) equipped with the standard euclidean form scaled by \(p ^ { - 1 }\) which we denote \[ \mathbb { Z } ^ { n } ( p ^ { - 1 } ) = \mathbb { O } ^ { n } \langle p ^ { - 1 } \rangle . \]

Lemma 5.1.2

FC11-C05-U006 · Chapter 5, source L3352-L3361

Lemma 5.1.2. 1. The sublattice \(p \mathbb { Z } ^ { n }\) of \(\Gamma _ { C }\) is isometric to \(\mathbb { O } ^ { n } \langle p \rangle\) . In particular, if \(p = 2\) , the root lattice \({ \mathfrak { Q } } ^ { n } A _ { 1 }\) is contained in \(\Gamma _ { C }\) . 2. \(\Gamma _ { C }\) is an integral lattice if and only if \(c\) is isotropic. 3. \(\Gamma _ { C } ^ { * } \subset \mathbb { Z } ^ { n } ( p ^ { - 1 } )\) . Moreover, if \(c\) is isotropic, the integral lattice \(\Gamma _ { C }\) is a \(p\) - elementary lattice, that is, we recall (cf. Subsection 1.7.B) \[ p \cdot \Gamma _ { C } ^ { * } \subset \Gamma _ { C } . \]

Proposition 5.1.4

FC11-C05-U008 · Chapter 5, source L3376-L3385

Proposition 5.1.4. Let \(C \subset \mathbb { F } _ { p } ^ { n }\) be an isotropic code and \(\Gamma _ { C } \subset \mathbb { Z } ^ { n } ( p ^ { - 1 } )\) the corresponding integral lattice. Then \(\Gamma _ { C }\) has the following properties: 1. \(\mathrm { d i s c } ( \Gamma _ { C } ) = p ^ { n - 2 m } , \quad m = \mathrm { d i m } { \cal C } .\) 2. Definition / construction / notation

FC11-C05-U012 · Chapter 5, source L3479

Reed-Muller codes. The definition of this class of codes runs as follows. Let \(I\) be a finite set of size \(N\) . Then the functions \(I \to \mathbb { F } _ { 2 }\) form the \(\mathbb { F } _ { 2 }\) -vector space \(\mathbb { F } _ { 2 } ^ { I }\) Suppose that itself consists of the points of an \(\mathbb { F } _ { 2 }\) -vector space \(W\) of dimension \(m\) so that \(N = 2 ^ { m }\) . We order these points as follows. Let \(\{ e _ { 0 } , \dotsc , e _ { m - 1 } \}\) be a basis for \(W\) and identify a point \(\begin{array} { r } { x = \sum _ { j = 0 } ^ { m - 1 } x _ { j } e _ { j } } \end{array}\) with the binary expansion \(\begin{array} { r } { n _ { x } = \sum _ { j = 0 } ^ { m - 1 } x _ { j } 2 ^ { j } } \end{array}\) of an integer between 0 and \(2 ^ { m } - 1\) . The natural order gives an ordering of the points of \(W\) . An ?? \(^ 2\) -valued function \(f\) on \(W\) determines a vector \(( f _ { 0 } , \dotsc , f _ { N - 1 } ) \in \mathbb { F } _ { 2 } ^ { N }\) as follows. First note that a point \(x \in W\) determines the unique integer \(j = n _ { x } \ \in\) \(\lfloor 0 , \ldots , N - 1 \rfloor\) and then we set \(f _ { j } = f ( x )\) . This way, the polynomial functions of degree \(k\) on \(W\) together with the zero function define a subspace of \(\mathbb { F } _ { 2 } ^ { N }\) and this is also the case for polynomial functions of degree \(\leq k\) . For \(0 \leq k < m\) , the latter define the \(k\) -th order Reed–Muller code \(S ^ { \le k } ( W ) \subset \mathbb { F } _ { 2 } ^ { N }\) , \(N = 2 ^ { m }\) . For an extensive treatment of these codes we refer to [140, Sect. 4.5.].

5.2.A Even sets of nodes. Let \(Y\) be a (connected compact and smooth) complex surface which is the minimal resolution of a singular surface \(Y ^ { \prime }\) having a finite set of ordinary double points (and no other singularities). The example to have in mind is the (singular) Kummer surface (see Appendix B.3). As in that example, each double point is resolved by a nodal curve, by definition a smooth rational curve with self-intersection \(- 2\) . Conversely, such a curve can be contracted to give a surface with an ordinary double point. A special role is played by subsets \(\{ E _ { j } \} _ { j \in J }\) of disjoint nodal curves for which \(\begin{array} { r } { B _ { J } = \sum _ { j \in J } E _ { j } \in 2 \mathsf { N S } ( Y ) } \end{array}\) . Such a set is called an even set of nodal curves.3 Its role is highlighted by the following geometric construction. Evenness implies that there is a double covering \(^ 4\) of \(Y\) , exactly ramified over \(B _ { J }\) .
