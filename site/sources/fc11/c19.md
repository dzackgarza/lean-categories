### Definition / construction / notation {#fc11-c19-u004}

::: {.unit-meta}
`FC11-C19-U004` · Chapter 19, source L9275-L9279
:::

For brevity, the classes of effective, respectively ample divisors in the N´eron– Severi lattice $\mathsf { N S } ( X )$ are called effective, respectively ample classes. Likewise, the class of a nodal curve is called a nodal class. Observe that nodal classes are roots in $\mathsf { N S } ( X )$ , but not conversely. In fact, $\left( - 2 \right)$ -roots in the N´eron–Severi lattice are classes of divisors $D$ with $D \cdot D = - 2$ which are not necessarily effective or irreducible. Reflections in $\left( - 2 \right)$ -roots in $\mathsf { N S } ( X )$ generate its Weyl group. Since the corresponding hyperplane reflections extend to $H ^ { 2 } ( X , \mathbb { Z } )$ , this group can be considered as a subgroup of $\mathsf { O } ( H ^ { 2 } ( X , \mathbb { Z } ) )$ . We call it the Weyl group of $X$ : $$ \mathsf { W } ^ { - } ( X ) : = \mathsf { W } ^ { - } ( \mathsf { N S } ( X ) ) \subset \mathsf { O } ( H ^ { 2 } ( X , \mathbb { Z } ) ) . $$

### Remark 19.2.12 {#fc11-c19-u028}

::: {.unit-meta}
`FC11-C19-U028` · Chapter 19, source L9424-L9426 · after [`FC11-C01-U053`](c01.html#fc11-c01-u053), [`FC11-C02-U014`](c02.html#fc11-c02-u014), [`FC11-C15-U014`](c15.html#fc11-c15-u014)

Remark 19.2.12. 1. In the non-algebraic situation $\mathsf { N S } ( X )$ can indeed be negative definite or have a one-dimensional null-space. The last two cases occur if and only if the function field of $X$ has transcendence degree $a ( X ) = 0$ , respectively $a ( X ) = 1$ . Indeed, if an isotropic $f \in \mathsf { N S } ( X )$ exists, then $\pm f$ is effective and one can show (cf. [124, Thm. 4.1,4.2]) that a suitable multiple defines an elliptic fibration. This implies that $a ( X ) \geq 1$ . If $a ( X ) = 2$ the surface $X$ is algebraic (cf. [15, Ch. IV. Corollary 6.5]) and its N´eron–Severi lattice is not negative semi-definite. If $\mathsf { N S } ( X )$ is negative definite, $X$ cannot be elliptic or algebraic, and hence $a ( X ) = 0$ . 2. By Theorem 15.2.6 any unimodular lattice $S$ of rank $\leq 2 0$ embeds uniquely in the K3 lattice provided $T = S ^ { \perp }$ is indefinite. This ceases to be true if $T$ is definite which may only occur in the non-algebraic situation. The simplest example is presented by the sublattice $S = \mathbb { O } ^ { 3 } U$ . In the standard embedding its orthogonal complement is $\mathbb { O } ^ { 2 } E _ { 8 } ( - 1 )$ . However, as we have seen (Example 1.5.1.2), there is another even unimodular rank 16 lattice which is negative definite and indecomposable, $\Gamma _ { 1 6 } ( - 1 )$ . By Theorem 2.4.1, which gives the classification of indefinite even unimodular lattices, $\Phi ^ { 3 } U \oplus \oplus ^ { 2 } E _ { 8 } ( - 1 ) \simeq \oplus ^ { 3 } U \oplus \Gamma _ { 1 6 } ( - 1 )$ . So two possible period domains then occur for (non-algebraic) K3 surfaces having the same N´eron–Severi lattice, but with different transcendental lattices.

19.5.B Supersingular K3-lattices. The N´eron–Severi lattices for supersingular K3 surfaces all belong to the class of the so-called supersingular K3-lattices defined below (cf. Definition 19.5.1).7 We explain how these can be classified using the theory we have developed. We also give their construction as given in loc. cit.

### Definition 19.5.1 {#fc11-c19-u043}

::: {.unit-meta}
`FC11-C19-U043` · Chapter 19, source L9588-L9593
:::

Definition 19.5.1. Let $p$ be a prime number. A non-degenerate quadratic lattice $N$ of rank $n$ is called a supersingular $\kappa \mathrm { 3 }$ -lattice with Artin invariant $\boldsymbol { \mathsf { O } }$ if 1. $n \equiv 6$ mod 8, 2. $N$ is Lorentzian, that is, its signature is $( 1 , n - 1 )$ , 3. $N$ is $p$ -elementary, i.e., $p N ^ { * } \subset N \subset N ^ { * }$ , 4. $N ^ { * } / N$ is an $\mathbb { F } _ { p }$ -vector space of even dimension $2 \sigma$ .

### Construction / comparison {#fc11-c19-u044}

::: {.unit-meta}
`FC11-C19-U044` · Chapter 19, source L9595 · after [`FC11-C19-U043`](#fc11-c19-u043)
:::

For a supersingular K3-lattice, the rank/signature conditions force index $4$ modulo $8$; at $p=2$, type I and type II are distinguished by whether the discriminant quadratic form is $\frac12\mathbf Z/\mathbf Z$-valued or assumes a quarter-integral value.

### Proposition 19.5.2 {#fc11-c19-u045}

::: {.unit-meta}
`FC11-C19-U045` · Chapter 19, source L9597-L9606 · after [`FC11-C19-U043`](#fc11-c19-u043)
:::

Proposition 19.5.2. For any odd prime $p$ a supersingular $K \mathcal { 3 }$ -lattice $N$ is uniquely determined by $n$ and $\boldsymbol { \mathsf { O } }$ with $n , \sigma$ as in Definition 19.5.1. Such lattices only exist if $0 < \sigma < { \textstyle { \frac { 1 } { 2 } } n }$ . If $p = 2$ we have $0 < \sigma \leq { \textstyle { \frac { 1 } { 2 } } } n$ . There are two types of discriminant forms: $$ \begin{array} { r l } & { \boldsymbol { q } ^ { \# } = \mathbb { O } ^ { \sigma - 1 } \boldsymbol { u } _ { 1 } \oplus \boldsymbol { v } _ { 1 } , 1 \le \sigma < \displaystyle \frac { 1 } { 2 } \boldsymbol { n } , \quad ( T y p e ~ I ) , } \\ & { \boldsymbol { q } ^ { \# } = \langle 2 ^ { - 1 } \rangle \oplus \langle 3 \cdot 2 ^ { - 1 } \rangle \oplus \mathbb { O } ^ { \sigma - 2 } \boldsymbol { u } _ { 1 } \oplus \boldsymbol { v } _ { 1 } , \sigma \ge 2 , \quad ( T y p e ~ I I ) . } \end{array} $$ If $\sigma = 1$ one has $q ^ { \# } = v _ { 1 }$ and if $\sigma \ = \ { \textstyle { \frac { 1 } { 2 } } } n$ , $q ^ { \# }$ is of type II. In all these cases there exists an up to isometry unique 2-elementary supersingular K3-lattice with discriminant form $q ^ { \# }$ .

Theorem ([199, §3,4]). Supersingular $K \mathcal { 3 }$ surfaces in characteristic 2 with Artin invariant $\sigma$ have a moduli variety $M _ { \sigma }$ of dimension $\sigma - 1$ . In other words, the points of $M _ { \sigma }$ are in one to one correspondence with isomorphism classes of supersingular $K \mathcal { 3 }$ surfaces with Artin invariant $\sigma$ .
