FC11 — Peters–Sterk, Symmetric and Quadratic Forms (June 2024)

FC11 — Peters & Sterk, Symmetric and Quadratic Forms.

This chapter contains 10 definitions, 8 theorems, 4 propositions, 5 lemmas, 6 corollaries, 8 examples, 4 constructions, 3 remarks, 1 convention and 1 criterion.

Nobody has checked this chapter against Lean yet, so the statements below say nothing about whether they are formalized.

Definition / construction / notation

FC11-C14-U001 · Chapter 14, source L7094

In this chapter \(L\) , \(L ^ { \prime }\) , \(L ^ { \prime \prime }\) , \(M\) are free \(\mathbb { Z }\) -modules of full rank within a quadratic innerproduct space \(( V , q )\) over \(\nsubseteq\) . In particular, \(V = L _ { \mathbb { Q } } = L _ { \mathbb { Q } } ^ { \prime } = L _ { \mathbb { Q } } ^ { \prime \prime } = M _ { \mathbb { Q } }\) . We write \(b , b ^ { \prime } , \ldots\) , for the polar forms of \(q , q ^ { \prime } , \ldots\) . Moreover the forms \(b , b ^ { \prime } , \ldots\) , induced on \(L , L ^ { \prime } , \ldots\) are assumed to be integer-valued. The localizations of \(V\) are \(( V _ { p } , q _ { p } )\) containing the local lattices \(L _ { p } , L , L _ { p } ^ { \prime } , \ldots\) .

Definition / construction / notation

FC11-C14-U002 · Chapter 14, source L7100

As explained in Section 14.1, the appropriate way to compare integral lattices in a given genus is to consider these as a full rank lattice of a fixed (quadratic) inner product space over the rational numbers, say \(V\) . Observe that this fixes the signature so that the place at infinity does not play a role. Isometric lattices \(L , L ^ { \prime }\) have isometric localizations \(L _ { v } \simeq L _ { v } ^ { \prime }\) and so by definition belong to the same genus and belong to the localization \(V _ { v }\) of \(V\) .

Proposition 14.1.1

FC11-C14-U003 · Chapter 14, source L7112-L7119

Proposition 14.1.1. Let \(L , M \subset V\) be free ℤ-submodules of \(V\) of maximal rank. Then 1. \(M = \gamma ( L )\) for some vector space isomorphism \(\gamma : V \to V\) . 2. \(L _ { p } = M _ { p }\) for almost all primes \(p\) . 3. \(L _ { p } = M _ { p }\) for all primes \(p\) if and only if \(L = M\) .

Theorem 14.1.2

FC11-C14-U004 · Chapter 14, source L7132-L7138

Theorem 14.1.2 (Glueing local lattices, [36, Ch.11, Thm. 1.1]). Let \(V\) be a finite dimensional vector space over \(\mathbb { Q }\) and let \(L\) be \(a\) free \(\mathbb { Z }\) -submodule of \(V\) of maximal rank. For every prime \(p\) , let \(M ^ { ( p ) }\) be a \(p\) -adic free \(\mathbb { Z } _ { p }\) -module of maximal rank in the localization \(V _ { p }\) of \(V\) . Then there exists a free \(\mathbb { Z }\) -submodule \(M\) of \(V\) of maximal rank whose localizations are \(M ^ { ( p ) }\) if and only if \[ M ^ { ( p ) } = L _ { p } \quad f o r \ a l m o s t \ a l l \ p r i m e s \ p . \] If \(M\) exists, it is uniquely determined by the condition \(M ^ { ( p ) } = M _ { p }\) for all primes \(p\) .

Definition / construction / notation

FC11-C14-U005 · Chapter 14, source L7140

When lattices in one genus are identified inside a fixed rational quadratic space \(V\), two sublattices are called equivalent if a rational isometry of \(V\) sends one to the other; they are genus-equivalent when this holds locally at every prime.

Definition / construction / notation

FC11-C14-U006 · Chapter 14, source L7142

If we follow the preceding convention, first of all, two sublattices \(L ^ { \prime } , L ^ { \prime \prime }\) of \(V\) are isometric precisely if there is a vector space isometry sending \(L ^ { \prime }\) to \(L ^ { \prime \prime }\) in which case we call \(L ^ { \prime }\) and \(L ^ { \prime \prime }\) equivalent lattices. Secondly, \(L ^ { \prime }\) and \(L ^ { \prime \prime }\) belong to the same genus precisely if for all primes \(p\) local isometries \(g _ { p }\) of \(V _ { p }\) exist with \(g _ { p } L _ { p } ^ { \prime } = L _ { p } ^ { \prime \prime }\) .

Definition / construction / notation

FC11-C14-U007 · Chapter 14, source L7144

It is natural to consider a more restricted form of equivalence between sublattices \(L ^ { \prime } , L ^ { \prime \prime }\) of \(V\) , namely equivalence under the rotation group \({ \mathsf { S O } } ( V , q )\) in which case we call the sublattices properly equivalent. The isometry group of the vector space \(V\) always contains isometries other than rotations, e.g., if \(\{ e _ { 1 } , \ldots , e _ { n } \}\) is an orthogonal basis, the linear map \(\tau\) sending \(e _ { 1 }\) to \(- e _ { 1 }\) and fixing all other basis elements is such an isometry. Then, by definition, the lattices \(L\) and \(L ^ { \prime } = \tau ( L )\) are equivalent, but they need not be properly equivalent as shown in Example 3 below.

Example / comparison

FC11-C14-U010 · Chapter 14, source L7150-L7152 · after FC11-C06-U062

In Example 6.5.5.4 we showed that \(\pm\) id are the only isometries of the integral quadratic form \(q ( x , y ) = a x ^ { 2 } + 2 x y + c y ^ { 2 }\) on \(\mathbb { Z } ^ { 2 }\) with \(a , c \in \mathbb { Z }\) and \(a \ge 2\) and \(c > a\) . Hence \({ \mathsf { S O } } ( q ) = { \mathsf { O } } ( q )\) . Now \(V = \mathbb { Q } e _ { 1 } \oplus \mathbb { Q } ( e _ { 1 } - a e _ { 2 } )\) and the reflection \(\tau\) in \(V\) with matrix \(\tau = { \binom { - 1 } { 0 } } ^ { - 2 a ^ { - 1 } } 1\) with respect to \(e _ { 1 } , e _ { 2 }\) is in \(\operatorname { O } ( V , q )\) , so maps \(\mathbb { Z } ^ { 2 }\) to the equivalent lattice \(\tau ( \mathbb { Z } ^ { 2 } )\) with basis \(\{ e _ { 1 } , - ( 2 / a ) e _ { 1 } + e _ { 2 } \}\) , and form (in corresponding coordinates) \(q ^ { \prime } = a u ^ { 2 } - 2 u v + c v ^ { 2 }\) . It is, however, not properly equivalent to \(q\) . This last example leads to the following observation.

Lemma 14.1.4

FC11-C14-U011 · Chapter 14, source L7154-L7156

Lemma 14.1.4. Let \(L\) be a sublattice of \(V\) of maximal rank. If every automorphism of \(L\) is a rotation, the equivalence class of \(L\) splits into two proper equivalence classes. If on the contrary \(L\) admits an isometry with determinant \(^ { - 1 }\) , then every lattice equivalent to \(L\) is also properly equivalent to it. In particular, if the genus of \(L\) consists of one equivalence class, then SO(??) is of index 2 in \(\mathrm { O } ( L )\) .

Construction / comparison

FC11-C14-U012 · Chapter 14, source L7158-L7162

For \(p\)-adic lattices, equivalence and proper equivalence coincide. Consequently two global lattices lie in the same genus exactly when at every place one can carry one localization to the other by an element of the local special orthogonal group.

Corollary 14.1.5

FC11-C14-U013 · Chapter 14, source L7166-L7176

Corollary 14.1.5. Let \(L ^ { \prime }\) be a lattice in \(V\) of maximal rank. 1. For every prime \(p\) let \(g _ { p } ^ { \prime } \in \mathsf { S O } ( V _ { p } , q _ { p } )\) . If \(g _ { p } ^ { \prime } \in \mathsf { S O } ( L _ { p } ^ { \prime } )\) for almost all \(p\) , then there is a unique lattice \(L ^ { \prime \prime }\) in \(V\) for which \[ L _ { p } ^ { \prime \prime } = g _ { p } ^ { \prime } L _ { p } ^ { \prime } \quad f o r \ a l l \ p . \] In particular \(L ^ { \prime }\) and \(L ^ { \prime \prime }\) belong to the same genus. 2. Conversely, if \(L ^ { \prime }\) and \(L ^ { \prime \prime }\) belong to the same genus, then for every prime \(p\) there exists \(g _ { p } ^ { \prime } \in \mathsf { S O } ( V _ { p } , q _ { p } )\) with \(L _ { p } ^ { \prime \prime } = g _ { p } ^ { \prime } L _ { p } ^ { \prime }\) , and \(g _ { p } ^ { \prime } \in \mathsf { S O } ( L _ { p } ^ { \prime } )\) for almost all \(p\) .

Definition 14.2.1

FC11-C14-U014 · Chapter 14, source L7185-L7189

Definition 14.2.1. We say that two sublattices \(L ^ { \prime } , L ^ { \prime \prime }\) of \(( V , q )\) (maximal rank) are spinor-equivalent or belong to the same spinor genus if there exist \(\gamma ^ { \prime } \in\) \({ \mathsf { S O } } ( V , q )\) and \(g _ { p } \in \mathsf { S O } ^ { + } ( V _ { p } , q _ { p } )\) for all primes \(p\) , such that \[ L _ { p } ^ { \prime \prime } = \gamma ^ { \prime } { \circ } g _ { p } ( L _ { p } ^ { \prime } ) \mathrm { ~ f o r ~ a l l ~ p r i m e s ~ } p . \]

Lemma 14.2.2

FC11-C14-U015 · Chapter 14, source L7205-L7208

Lemma 14.2.2. 1. Properly equivalent lattices are spinor equivalent; 2. Spinor equivalent lattices are in the same genus.

Convention / notation

FC11-C14-U016 · Chapter 14, source L7211-L7213

For a lattice and its localizations, the book extends the notation for the image of the spinor norm to the corresponding global and local orthogonal groups.

Lemma 14.2.3

FC11-C14-U017 · Chapter 14, source L7219-L7220

Lemma 14.2.3. Suppose that \(n = \dim V \geq 3\) . Then \(\mathsf { S } _ { V }\) contains \(\mathbb { Q } _ { > 0 } \cdot ( \mathbb { Q } ^ { \times } ) ^ { 2 }\) . If \(q\) is indefinite, the spinor norm map is surjective: \(\mathsf { S } _ { V } = \mathsf { D } ( \mathbb { Q } )\) .

Example / comparison

FC11-C14-U019 · Chapter 14, source L7239-L7243 · after FC11-C14-U014

Consider the integral lattice \(L = A _ { 2 }\) with quadratic form \(x ^ { 2 } + x y + y ^ { 2 }\) . This lattice is positive definite and has discriminant 3. For primes \(p \neq 3\) the lattice \(L _ { p }\) is unimodular and then, by the argument of example 1, \(\mathsf { S } _ { L _ { p } } = \mathbb { Z } _ { p } ^ { \times } \cdot ( \mathbb { Q } _ { p } ^ { \times } ) ^ { 2 }\) . For the prime 3 the situation is different since the lattice \(L _ { 3 }\) is not unimodular. The basis \(e _ { 1 } = ( 1 , 0 )\) , \(e _ { 2 } = ( - 1 , 2 )\) exhibits \(L _ { 3 } \simeq [ 1 ] \odot\) [3] and the corresponding reflections \(\sigma _ { e _ { 1 } }\) and \(\sigma _ { e _ { 2 } }\) have spinor norm 1, respectively 3. Since \(q ( x e _ { 1 } + y e _ { 2 } ) =\) \(x ^ { 2 } + 3 y ^ { 2 }\) cannot be of the form \(- z ^ { 2 }\) in \(\mathbb { Q } _ { 3 }\) (a square is 1 modulo 3), the group \(\mathsf { S } _ { L _ { 3 } }\) is the cyclic group of order 2 generated by the class of \({ 1 \cdot 3 }\) and so again is strictly smaller than \(\mathsf { D } ( \mathbb { Q } _ { 3 } )\) . The next result demonstrates how to use information about the images of the local spinor norms to deduce that the genus of \(L\) contains only one spinor genus:
