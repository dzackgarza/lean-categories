In Section 20.1 we describe the automorphism group of a K3 surface through the action on cohomology, making use of the Torelli theorem 19.2.1. By definition, the subgroup of symplectic automorphisms is the subgroup fixing a holomorphic 2-form. For algebraic K3 surfaces this group is of finite index in the full group and the quotient group is well understood. This gives a finiteness criterion for automorphisms in terms of the N´eron–Severi lattice.

Criterion 20.1.3 ([189, §7, Theorem 1]). The automorphism group of a complex projective $K \mathcal { 3 }$ surface $X$ is finite if and only if $0 ^ { - } ( S ) / \mathsf { W } ^ { - } ( S )$ is finite. In other words, ${ \mathrm { A u t } } ( X )$ is finite if and only if the Weyl group of $X$ (cf. 19.1) embeds as a finite index subgroup in the isometry group of the N´eron–Severi lattice $S$ .

Theorem 20.9.6. Let $X$ be a compact complex surface admitting an action by a finite abelian group $G$ of order $n$ , let $\pi : X \to Y = X / G$ be the quotient map, $\widetilde { Y }$ the minimal resolution of singularities of $Y$ , $X ^ { \prime }$ the complement of the fixed points of $G$ , $Y ^ { \prime } = X ^ { \prime } / G$ , and $j ^ { \prime } : X ^ { \prime } \hookrightarrow X$ , ${ \widetilde { j } } : Y ^ { \prime } \hookrightarrow { \widetilde { Y } }$ the inclusions. Assume that $Y : = X / G$ has at most cyclic quotient singularities, that $X$ is simply connected and that $H _ { 1 } ( \widetilde { Y } ) = 0$ . Then the following assertions hold: 1. Setting $\theta : = ( j ^ { \prime } { } ^ { * } ) ^ { - 1 } \circ \pi ^ { * } \circ { \widetilde { j } } ^ { * } : H ^ { 2 } ( { \widetilde { Y } } ) H ^ { 2 } ( X ) ^ { G }$ , the image of $\theta$ belongs to H (cf. (20.23)) and there is an exact sequence $$ 0 \to M _ { Y } / M _ { Y } ^ { \prime } \to H ^ { 2 } ( \widetilde { Y } ) / M _ { Y } ^ { \prime } \overset { \theta } { \to } \mathsf { H } \to 0 . $$ The factor group ${ M _ { Y } } / { M _ { Y } ^ { \prime } }$ is canonically isomorphic to $\operatorname { E x t } ^ { 1 } ( G )$ . 2. $\theta$ induces an isomorphism $H ^ { 2 } ( \widetilde { Y } ) / M _ { Y } \stackrel { \simeq } { } \mathsf { H }$ and an injection $M _ { Y } ^ { \bot } \hookrightarrow \mathsf { H }$ . This is an injection of free $\mathbb { Z }$ -modules of the same rank, but $\theta | _ { M _ { Y } ^ { \perp } }$ multiplies the intersection form with $| G |$ . In case $G$ is cyclic, ${ \mathsf { H } } = H ^ { 2 } ( X ) ^ { G }$ . 3. The elementary divisors $e _ { 1 } | e _ { 2 } | \cdots | e _ { r }$ of the discriminant group of $M _ { Y }$ all divide $n = | G |$ . 4. The length of the discriminant group of the sublattice $\mathsf { H } \subset H ^ { 2 } ( X )$ is at least equal to $\mathrm { r a n k } ( H ^ { 2 } ( X ) ^ { G } ) - r$ . Its elementary divisors are obtained by omitting the integers equal to 1 from the list $( n / e _ { 1 } , \ldots , n / e _ { r } , n , \ldots , n )$ (the size of this list equals $\operatorname { r a n k } ( \mathsf { H } ) = \operatorname { r a n k } ( H ^ { 2 } ( X ) ^ { G } ) = b _ { 2 } ( { \bar { Y } } ) - \operatorname { r a n k } ( M _ { Y } ) )$ . A generalized Shioda--Inose structure is a triple $(X,A,G)$ in which $X$ is a K3 surface, $A$ an abelian surface, $G$ acts symplectically on $X$ and finitely on $A$, and the quotients $X/G$ and $A/G$ give the same generalized Kummer surface.
