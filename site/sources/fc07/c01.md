### Definition — path and homotopy of paths {#fc07-c01-u001}

::: {.unit-meta}
`FC07-C01-U001` · §1.1 Paths and Homotopy; source L609 · after [`FC07-C00-U005`](c00.html#fc07-c00-u005) · [in Mathlib]{.route-mathlib}
:::

A path in X is a continuous f:I→X. Two paths f_0,f_1 with the same endpoints are homotopic rel {0,1} when joined by a homotopy fixing both endpoints.

::: {.unit-lean}
**Formalized.** [`Mathlib/Topology/Homotopy/Path.lean::Path.Homotopy`](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Topology/Homotopy/Path.html#Path.Homotopy), [`Path.Homotopic`](https://leanprover-community.github.io/mathlib4_docs/find/?pattern=Path.Homotopic#doc) — Homotopy rel endpoints is exactly Mathlib path homotopy; the endpoint constraints are built into the dependent path types.
:::

### Example 1.1 {#fc07-c01-u002}

::: {.unit-meta}
`FC07-C01-U002` · §1.1 Paths and Homotopy; source L618 · [in Mathlib]{.route-mathlib}
:::

Linear Homotopies. Any two paths f_{0} and f_{1} in ℝ^{n} having the same endpoints x_{0} and x_{1} are homotopic via the homotopy f_{t} (s) = (1 - t) f_{0} (s) + t f_{1} (s). Continuity of the homotopy f_{t} as a map I × I → ℝ^{n} follows from continuity of f_{0} and f_{1} since the algebraic operations of vector addition and scalar multiplication in the formula for f_{t} are continuous.

::: {.unit-lean}
**Formalized.** [`Mathlib/Topology/Homotopy/Affine.lean::ContinuousMap.Homotopy.affine`](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Topology/Homotopy/Affine.html#ContinuousMap.Homotopy.affine) — The affine homotopy is the straight-line homotopy between maps into a convex set, giving the stated linear path homotopy in Euclidean space.
:::

[Searched: P=db584cd6d46c92f209a44c0f1c829460d327499d; Apache-2.0; Lean 4.33.0]{.unit-provenance}
