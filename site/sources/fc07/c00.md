### Definition — deformation retraction {#fc07-c00-u001}

::: {.unit-meta}
`FC07-C00-U001` · Homotopy and Homotopy Type; source L218 · [in another Lean project]{.route-reference-port}
:::

A deformation retraction of X onto A is a continuous family f_t:X→X with f_0=id_X, f_1(X)=A, and f_t|_A=id_A for all t.

::: {.unit-lean}
**Formalized.** `deancureton/sphere-six-complex::SphereSixComplex/Topology/EstablishedStrongDeformationRetracts.lean::SphereSixComplex.StrongDeformationRetraction` — The structure records a self-retraction with image in the specified subspace, identity on that subspace, and a homotopy from the identity to the retraction fixed pointwise on the subspace. Together `retract_mem` and `retract_fixed` give image exactly the subspace, matching Hatcher’s deformation-retraction convention.
:::

### Definition — homotopy equivalence and homotopy type {#fc07-c00-u006}

::: {.unit-meta}
`FC07-C00-U006` · Homotopy and Homotopy Type; source L244 · after [`FC07-C00-U003`](#fc07-c00-u003) · [in Mathlib]{.route-mathlib}
:::

A map f:X→Y is a homotopy equivalence if some g:Y→X satisfies fg≃id_Y and gf≃id_X; then X and Y have the same homotopy type.

::: {.unit-lean}
**Formalized.** [`Mathlib/Topology/Homotopy/Equiv.lean::ContinuousMap.HomotopyEquiv`](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Topology/Homotopy/Equiv.html#ContinuousMap.HomotopyEquiv) (`X ≃ₕ Y`) — The structure consists of continuous maps in both directions whose two composites are homotopic to the appropriate identities. Existence of this structure is precisely equality of homotopy type in the source sense.
:::
