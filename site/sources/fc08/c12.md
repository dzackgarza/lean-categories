### Definition/convention — multilinear {#fc08-c12-u001}

::: {.unit-meta}
`FC08-C12-U001` · Ch. 12, § Multilinear Algebra; source L8889 · [in Mathlib]{.route-mathlib}
:::

Suppose $V_{1},\dots,V_{k}$ and $W$ are vector spaces. A map $F \colon V_{1} \times \cdots \times V_{k} \to W$ is multilinear if it is linear in each variable separately when the others are held fixed: for each $i$, $$ F(v_{1},\dots,av_{i} + a'v_{i}',\dots,v_{k}) = aF(v_{1},\dots,v_{i},\dots,v_{k}) + a'F(v_{1},\dots,v_{i}',\dots,v_{k}). $$ The multilinear maps form a vector space $\operatorname{L}(V_{1},\dots,V_{k};W)$ under pointwise addition and scalar multiplication.

::: {.unit-lean}
**Formalized.** [`Mathlib/LinearAlgebra/Multilinear/Basic.lean::MultilinearMap`](https://leanprover-community.github.io/mathlib4_docs/Mathlib/LinearAlgebra/Multilinear/Basic.html) — `MultilinearMap ℝ V W` is precisely a map linear in each argument separately. Its dependent-domain form covers Lee’s possibly different vector spaces `V₁,…,Vₖ`.
:::

### Definition/convention — formal linear combination of elements of S {#fc08-c12-u005}

::: {.unit-meta}
`FC08-C12-U005` · Ch. 12, § Abstract Tensor Products of Vector Spaces; source L8999 · [in Mathlib]{.route-mathlib}
:::

simple.) To begin, we need to make sense of “formal linear combinations.” Let S be a set. Roughly speaking, a formal linear combination of elements of S is an expression of the form $\scriptstyle \sum _ { i = 1 } ^ { m } a _ { i } x _ { i }$ , where $a _ { 1 } , \ldots , a _ { m }$ are real numbers and $x _ { 1 } , \ldots , x _ { m }$ are elements of S. Of course, since we are not assuming that S has any algebraic structure, we cannot literally add elements of S together or multiply them by numbers. But the essential feature of such an expression is that it is completely determined by which elements of S appear in the sum, and what coefficients appear with them. Thus, we make the following definition: for any set S, a formal linear combination of elements of S is a function $f \colon S \to \mathbb { R }$ such that $f ( s ) = 0$ for all but finitely many $s \in S$ . The free (real) vector space on S , denoted by ${ \mathcal { F } } ( S )$ , is the set of all formal linear combinations of elements of S. Under pointwise addition and scalar multiplication, ${ \mathcal { F } } ( S )$ becomes have $d f = \omega$ , thus completing the proof.

### Construction/definition — the (abstract) tensor product of v {#fc08-c12-u008}

::: {.unit-meta}
`FC08-C12-U008` · Ch. 12, § Abstract Tensor Products of Vector Spaces; source L9019 · [in Mathlib]{.route-mathlib}
:::

The tensor product of $V_{1},\dots,V_{k}$ is the quotient vector space $$ V_{1} \otimes \cdots \otimes V_{k} = \mathcal{F}(V_{1} \times \cdots \times V_{k})/\mathcal{R}, $$ with natural projection $\pi$. The class of $(v_{1},\dots,v_{k})$ is written $$ v_{1} \otimes \cdots \otimes v_{k} = \pi(v_{1},\dots,v_{k}), \tag{12.5} $$ the abstract tensor product of $v_{1},\dots,v_{k}$. It follows that $v_{1} \otimes \cdots \otimes av_{i} \otimes \cdots \otimes v_{k} = a(v_{1} \otimes \cdots \otimes v_{i} \otimes \cdots \otimes v_{k})$ and $v_{1} \otimes \cdots \otimes (v_{i}+v_{i}') \otimes \cdots \otimes v_{k} = (v_{1} \otimes \cdots \otimes v_{i} \otimes \cdots \otimes v_{k}) + (v_{1} \otimes \cdots \otimes v_{i}' \otimes \cdots \otimes v_{k})$. Every element of the tensor product is a linear combination of elements $v_{1} \otimes \cdots \otimes v_{k}$, though not in general of that form itself.
