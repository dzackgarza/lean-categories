### **Convention/notation — vector field** {#fc08-c08-u001}

::: {.unit-meta}
`FC08-C08-U001` · Ch. 8, § Vector Fields on Manifolds; source L4877 · [`unmatched`]{.route-unmatched}
:::

If M is a smooth manifold with or without boundary, a vector field on M is a section of the map π : T M → M . More concretely, a vector field is a continuous map X : M → T M ; usually written p ↦ X _p , with the property that π ∘ X = Id _M,tag8.1 or equivalently, X _p ∈ T _p M for each p ∈ M . (We write the value of X at p as X _p instead of X ( p ) to be consistent with our notation for elements of the tangent bundle, as well as to avoid conflict with the notation v ( f ) for the action of a vector on a function.) You should visualize a vector field on M in the same way as you visualize vector fields in Euclidean space: as an arrow attached to each point of M; chosen to be tangent to M and to vary continuously from point to point (Fig. 8.1).

### **Convention/notation — global frame** {#fc08-c08-u015}

::: {.unit-meta}
`FC08-C08-U015` · Ch. 8, § Local and Global Frames; source L4976 · [`unmatched`]{.route-unmatched}
:::

Suppose M is a smooth n-manifold with or without boundary. An ordered k - tuple ( X _1 , … , X _k ) of vector fields defined on some subset A ⊆ M is said to be linearly independent if ( X _1 ∣ _p , … , X _k ∣ _p ) is a linearly independent k-tuple in T _p M for each p ∈ A , and is said to span the tangent bundle if the k-tuple ( X _1 ∣ _p , … , X _k ∣ _p ) spans T _p M at each p ∈ A . A local frame for M is an ordered n-tuple of vector fields ( E _1 , … , E _n ) defined on an open subset U ⊆ M that is linearly independen and spans the tangent bundle; thus the vectors ( E _1 ∣ _p , … , E _n ∣ _p ) form a basis for T _p M at each p ∈ U . It is called a global frame if U = M ; and a smooth frame if each of the vector fields E _i is smooth. We often use the shorthand notation ( E _i ) to denote a frame ( E _1 , … , E _n ) . If M has dimension n, then to check that an ordered n-tuple of vector fields ( E _1 , … , E _n ) is a local frame, it suffices to check either that it is linearly independent or that it spans the tangent bundle.
