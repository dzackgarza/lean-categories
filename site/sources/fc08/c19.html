Definition/convention — smooth distribution

FC08-C19-U001 · Ch. 19, § Distributions and Involutivity; source L14751 · not formalized

Let M be a smooth manifold. A distribution on M of rank k is a rank-k subbundle of TM . It is called a smooth distribution if it is a smooth subbundle. Distributions are also sometimes called tangent distributions (especially if there is any opportunity for confusion with the use of the term distribution for generalized functions in analysis), k-plane fields, or tangent subbundles.

Definition/convention — rank-k distribution

FC08-C19-U002 · Ch. 19, § Distributions and Involutivity; source L14753 · after FC08-C10-U046 · not formalized

Often a rank-k distribution is described by specifying for each \(p \in M\) a linear subspace \(D _ { p } \subseteq T _ { p } M\) of dimension k, and letting \(\textstyle D = \bigcup _ { p \in M } D _ { p }\) . It then follows from the local frame criterion for subbundles (Lemma 10.32) that D is a smooth distribution if and only if each point of M has a neighborhood \(U\) on which there are smooth vector fields \(X _ { 1 } , \dots , X _ { k } \colon U T M\) such that \(X _ { 1 } | _ { q } , \ldots , X _ { k } | _ { q }\) form a basis for \(D _ { q }\) at each \(q \in U\) . In this case, we say that \(D\) is the distribution (locally) spanned by the vector fields \(X _ { 1 } , \ldots , X _ { k }\)

Definition/convention — local defining forms for D

FC08-C19-U011 · Ch. 19, § Involutivity and Differential Forms; source L14826 · not formalized

If \(D\) is a rank-\(k\) distribution on a smooth \(n\)-manifold \(M\), any \(n-k\) linearly independent 1-forms \(\omega^{1},\dots,\omega^{n-k}\) defined on an open subset \(U \subseteq M\) and satisfying (19.1) at each \(q \in U\) are local defining forms for \(D\). More generally, for \(0 \leq p \leq n\), a \(p\)-form \(\omega \in \Omega^{p}(M)\) annihilates \(D\) if \(\omega(X_{1},\dots,X_{p}) = 0\) whenever \(X_{1},\dots,X_{p}\) are local sections of \(D\); for \(p = 0\) only the zero function annihilates \(D\).
