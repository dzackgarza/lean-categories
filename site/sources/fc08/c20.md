### Definition/convention — left-invariant {#fc08-c20-u026}

::: {.unit-meta}
`FC08-C20-U026` · Ch. 20, § Lie’s Fundamental Theorems; source L16043 · [not formalized]{.route-unmatched}
:::

The left translation map $L _ { g } \colon U \to V$ is defined just as for ordinary Lie groups, and a vector field $X \in { \mathfrak { X } } ( U )$ is said to be left-invariant if $d ( L _ { g } ) _ { g ^ { \prime } } ( X _ { g ^ { \prime } } ) = X _ { m ( g , g ^ { \prime } ) }$ for all $g , g ^ { \prime } \in U$ such that $m ( g , g ^ { \prime } ) \in U$ . Two local Lie groups $( U , e , m , i )$ and $( U ^ { \prime } , e ^ { \prime } , m ^ { \prime } , i ^ { \prime } )$ are said to be locally isomorphic if there is a diffeomorphism from a neighborhood of $e$ in $U$ to a neighborhood of $e ^ { \prime }$ in $U ^ { \prime }$ that takes $e$ to $e ^ { \prime } .$ , m to $m ^ { \prime }$ , and i to $i ^ { \prime }$ , whenever the respective operations are defined. A local (left or right) action of a local Lie group on an open subset $W \subseteq \mathbb { R } ^ { n }$ is defined like an ordinary action, except that $g \cdot x \left( \operatorname { o r } x \cdot g \right)$ is required to be defined only for $( g , x )$ in a neighborhood of $\{ e \} \times W$ in $U \times W$ .
