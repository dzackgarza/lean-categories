Chapter 4. Adjunctions

FC03 — Riehl, Category Theory in Context.

This chapter contains 13 definitions, 6 theorems, 10 propositions, 8 lemmas, 10 corollaries, 20 examples, 2 constructions, 2 remarks, 1 notation and 4 other statements.

Nobody has checked this chapter against Lean yet, so the statements below say nothing about whether they are formalized.

Definition 4.1.1

FC03-C04-U001 · §4.1, pp. 116–121; L3847 · after FC03-C01-U028, FC03-C01-U049

An adjunction F:C→D ⊣ G:D→C is a natural family of bijections D(Fc,d) ≅ C(c,Gd), natural in c and d; F is the left adjoint, G the right adjoint, and corresponding morphisms are transposes.

Lemma 4.1.3

FC03-C04-U002 · §4.1, pp. 116–121; L3885 · after FC03-C01-U028, FC03-C01-U049

Consider a pair of functors \(F \colon \mathsf{C} \to \mathsf{D}\) and \(G \colon \mathsf{D} \to \mathsf{C}\) equipped with isomorphisms \(\mathsf{D}(Fc,d) \cong \mathsf{C}(c,Gd)\) for all \(c \in \mathsf{C}\) and \(d \in \mathsf{D}\). Naturality of this collection of isomorphisms is equivalent to the assertion that, for every \(f \colon c' \to c\) in \(\mathsf{C}\), every \(g \colon d \to d'\) in \(\mathsf{D}\) and every \(k \colon Fc \to d\) with transpose \(k^{\sharp} \colon c \to Gd\), \[ (g \cdot k \cdot Ff)^{\sharp} = Gg \cdot k^{\sharp} \cdot f, \] that is, the square (4.1.4) commutes in \(\mathsf{D}\) if and only if its transposed square commutes in \(\mathsf{C}\).

Notation 4.1.5

FC03-C04-U003 · §4.1, pp. 116–121; L3893 · after FC03-C01-U028, FC03-C01-U049

Write F ⊣ G (equivalently G ⊢ F) to assert that F:C→D is left adjoint to G:D→C.

Example 4.1.6

FC03-C04-U004 · §4.1, pp. 116–121; L3903 · after FC03-C01-U028, FC03-C01-U049

The forgetful functor U : Top Set admits both left and right adjoints. The left adjoint constructs a topological space from a set S in such a way that continuous maps from this space to another space T correspond naturally and bijectively to functions \(S \to U ( T )\) . The discrete topology on S has this universal property: writing \(D ( S )\) for this discrete space, any function \(S \to U ( T )\) defines a continuous map \(D ( S ) \to T\)

Definition/comparison

FC03-C04-U005 · §4.1, pp. 116–121; L3915 · after FC03-C01-U028, FC03-C01-U049

An adjunction between preorders is a monotone Galois connection: order-preserving F:A→B and G:B→A satisfy F(a)≤b iff a≤G(b).

Example 4.1.7

FC03-C04-U006 · §4.1, pp. 116–121; L3921 · after FC03-C01-U028, FC03-C01-U049

The inclusion of posets \(\mathbb { Z } \hookrightarrow \mathbb { R }\) , with the usual ordering , has both left and right adjoints, namely, the ceiling and floor functions. For any integer n and real number \(r , n \leq r \mathrm { i f }\) and only if \(n \leq \lfloor r \rfloor\) , where \(\lfloor r \rfloor\) denotes the greatest integer less than or equal to r. This function is order-preserving, defining a functor \(\lfloor - \rfloor \colon \mathbb { R } \to \mathbb { Z }\) that is right adjoint to the inclusion \(\mathbb { Z } \hookrightarrow \mathbb { R }\) . Dually, \(r \leq n\) if and only if \(\lceil r \rceil \leq n ,\) and this order-preserving function defines a functor \(\lceil - \rceil : \mathbb { R } \to \mathbb { Z }\) that is left adjoint to the inclusion.

Example 4.1.8

FC03-C04-U007 · §4.1, pp. 116–121; L3925 · after FC03-C01-U028, FC03-C01-U049

Consider a function \(f \colon A \to B\) between sets. The subsets of A and subsets of B form posets, PA and \(P B ,\) ordered by inclusion. The map f induces direct image and inverse image functors \(f _ { * } \colon P A \to P B\) and \(f ^ { - 1 } \colon P B \to P A\) The inverse image is right adjoint to the direct image: for \(A ^ { \prime } \subset A\) and \(B ^ { \prime } \subset B , f ( A ^ { \prime } ) \subset B ^ { \prime }\) if and only if \(A ^ { \prime } \subset f ^ { - 1 } ( B ^ { \prime } )\)

Example 4.1.9

FC03-C04-U008 · §4.1, pp. 116–121; L3931 · after FC03-C01-U028, FC03-C01-U049

A propositional function is a function \(P \colon X \Omega = { \bot , \top }\) , which we interpret as declaring, for each \(x \in X ,\) , whether \(P ( x )\) is true or false. The set \(\Omega ^ { X }\) is then the set of propositional functions on X. The set Ω is given the partial order \(\perp \le \top\) from which \(\Omega ^ { X }\) inherits a pointwise-defined order: \(P \leq Q\) if and only if \(P ( x ) \leq Q ( x )\) for all \(x \in X\) which is the case if and only if \(P\) implies \(Q .\)

Example 4.1.10

FC03-C04-U009 · §4.1, pp. 116–121; L3945 · after FC03-C01-U028, FC03-C01-U049

There is a large and very important family of “free forgetful” adjunctions \[ \mathsf {A} \xrightarrow [ U ]{\stackrel {{F}} {\perp}} \mathsf {S}, \] with the forgetful functor U defining the right adjoint and the free functor F defining the left adjoint. If one can construct a universal object of type A on an object of type S, and this construction defines a left adjoint to a forgetful functor \(U \colon \mathsf { A } \mathsf { S }\) , then the term “free” is used in place of “universal” to convey this particular relationship. The reason why left adjoints to forgetful functors are more common than right adjoints has to do with the handedness of the universal properties that one meets in practice. “Cofree” constructions, which define right adjoints to some forgetful functor, are somehow less common. The following forgetful functors admit left adjoints, defining “free” constructions.

Construction: For a ring map φ:R→S, restriction of scalars φ:ModS→ModR has left adjoint…

FC03-C04-U010 · §4.1, pp. 116–121; L3977 · after FC03-C01-U028, FC03-C01-U049

For a ring map φ:R→S, restriction of scalars φ*:Mod_S→Mod_R has left adjoint S⊗_R−, called extension of scalars.

Example 4.1.11

FC03-C04-U011 · §4.1, pp. 116–121; L3985 · after FC03-C01-U028, FC03-C01-U049

Example 4.1.10(xiii) can be generalized: Example 6.2.8 proves that for any complete and cocomplete category C and any group homomorphism φ: \(H \to G ,\) , the restriction functor \(\phi ^ { * } \colon { \mathsf { \bar { C } } } ^ { \mathsf { B } G } \to { \mathsf { \bar { C } } } ^ { \mathsf { B } H }\) admits both left and right adjoints. These are most commonly considered for subgroup inclusions \(H \subset G .\) , in which case the left adjoint is called induction and the right adjoint is called coinduction: Taking \(\mathsf { C } \ = \ \mathsf { V e c t _ { \mathbb { k } } }\) , the adjunction \(\mathrm { i n d } _ { H } ^ { G } \ \mathsf { \Pi } \mathsf { \Pi } \mathsf { I } \mathrm { e s } _ { H } ^ { G }\) between the category \(\mathsf { V e c t } _ { \parallel _ { \mathsf { k } } } ^ { \mathsf { B } H }\) of \(H -\) representations and the category of \(\mathsf { V e c t } _ { \Bbbk } ^ { \mathsf { B } \bar { G } }\) of \(G \mathrm { . }\) -rep resentations. This adjunction is known in the representation theory literature as Frobenius reciprocity.

Example 4.1.12

FC03-C04-U012 · §4.1, pp. 116–121; L3991 · after FC03-C01-U028, FC03-C01-U049

None of the functors \[ \text { Field } \xrightarrow {U} \text { Ring }, \quad \text { Field } \xrightarrow {U} \text { Ab }, \quad \text { Field } \xrightarrow {(-) ^ {\times}} \text { Ab }, \quad \text { Field } \xrightarrow {U} \text { Set } \] that forget algebraic structure on fields admit left or right adjoints. To see that no left adjoint is possible, note that there exist maps in the target categories from \(\mathbb { Z }\) to fields of any characteristic. As there are no field homomorphisms between fields of difering characteristic, it is not possible to define the value of a hypothetical left adjoint on \(\mathbb { Z } .\) . A similar argument can be used to show that no right adjoints to these functors exist.

Example 4.1.13

FC03-C04-U013 · §4.1, pp. 116–121; L3999 · after FC03-C01-U028, FC03-C01-U049

The forgetful functor U : Cat DirGraph admits a left adjoint \(F ,\) defining the free category on a directed graph. A directed graph G consists of a set V of vertices, a set \(E\) of edges, and two functions \(s , t \colon E \preceq V\) defining the source and target of each directed edge. The free category on G has V as its set of objects. The set of morphisms consists of identities for each vertex together with finite “paths” of edges. Composition is defined by concatenation of paths.

Example 4.1.14

FC03-C04-U014 · §4.1, pp. 116–121; L4005 · after FC03-C01-U028, FC03-C01-U049

Let \(\mathbb{n}+\mathbb{1}\) denote the ordinal category, freely generated by the directed graph \(0 \to 1 \to 2 \to \cdots \to n\). For each \(0 \leq i \leq n\) there is an injective functor \(d^{i} \colon \mathbb{n} \to \mathbb{n}+\mathbb{1}\), where \(i \in \mathbb{n}+\mathbb{1}\) is the unique object missing from the image. For each \(0 \leq i < n\) there is also a surjective functor \(s^{i} \colon \mathbb{n}+\mathbb{1} \to \mathbb{n}\), for which \(i \in \mathbb{n}\) is the unique object with two preimages. These functors define a sequence of \(2n+1\) adjoints \[ d^{0} \dashv s^{0} \dashv d^{1} \dashv s^{1} \dashv \cdots \dashv s^{n-1} \dashv d^{n}, \] proving that arbitrarily long finite sequences of adjoint functors exist.

Example 4.1.15

FC03-C04-U015 · §4.1, pp. 116–121; L4013 · after FC03-C01-U028, FC03-C01-U049

The inclusion \(\mathsf{Groupoid} \hookrightarrow \mathsf{Cat}\) admits both a left and a right adjoint. The right adjoint carries a category to its maximal subgroupoid, considered in Lemma 1.1.13: since functors preserve isomorphisms, the image of a functor \(\mathsf{G} \to \mathsf{C}\) whose domain is a groupoid factors uniquely through the maximal subgroupoid of \(\mathsf{C}\). The left adjoint formally inverts the morphisms of a category, constructing the corresponding category of fractions. The category of fractions for \(\mathsf{C}\) is a quotient of the free category on the directed graph obtained by gluing the directed graph underlying \(\mathsf{C}\) to the directed graph underlying \(\mathsf{C}^{\mathrm{op}}\) along the common discrete subcategory \(\mathrm{ob}\,\mathsf{C}\). Its objects are the objects of \(\mathsf{C}\) and its morphisms are finite zig-zags of morphisms of \(\mathsf{C}\), subject to relations that, for instance, equate the zig-zags \[ a \xrightarrow{\ f\ } b \xleftarrow{\ f\ } a \qquad\text{and}\qquad b \xleftarrow{\ f\ } a \xrightarrow{\ f\ } b \] with the identities on \(a\) and on \(b\).

Lemma 4.2.2

FC03-C04-U016 · §4.2, pp. 122–125; L4065 · after FC03-C01-U028, FC03-C01-U049

Given an adjunction \(F \to G ,\) , there is a natural transformation η : \(1 _ { \mathsf { C } } \Rightarrow G F ,\) called the unit of the adjunction, whose component \(\eta _ { c } \colon c \to G F c\) at c is defined to be the transpose of the identity morphism \(1 _ { F c }\)

Lemma 4.2.3

FC03-C04-U017 · §4.2, pp. 122–125; L4077 · after FC03-C01-U028, FC03-C01-U049

Given an adjunction \(F \to G ,\) , there is a natural transformation \(\epsilon \colon F G \Rightarrow 1 _ { \mathsf { D } } ,\) called the counit of the adjunction, whose component $_ { d } F G d $ d at d is defined to be the transpose of the identity morphism \(1 _ { G d } .\)

Example 4.2.4

FC03-C04-U018 · §4.2, pp. 122–125; L4079 · after FC03-C01-U028, FC03-C01-U049

The left adjoint F to the forgetful functor \(U \colon { \mathsf { G r o u p } } \to { \mathsf { S e t } }\) defines the free group on a set S . Elements of the group \(F ( S )\) are finite “words” whose “letters” are elements s of S and formal “inverses” \(s ^ { - 1 }\) , modulo some evident relations. The empty word serves as the identity element and multiplication is by concatenation; the relations, in particular, identify \(s s ^ { - 1 }\) and \(s ^ { - 1 } s\) with the empty word.

Construction/terminology

FC03-C04-U019 · §4.2, pp. 122–125; L4085 · after FC03-C01-U028, FC03-C01-U049

For an adjunction, components of the unit and counit are the universal elements representing the adjunction hom-set bijections.

Definition 4.2.5

FC03-C04-U020 · §4.2, pp. 122–125; L4095 · after FC03-C01-U028, FC03-C01-U049

An adjunction may equivalently be specified by F:C→D, G:D→C, a unit η:1_C⇒GF and counit ε:FG⇒1_D satisfying the triangle identities Gε·ηG=1_G and εF·Fη=1_F.

Proposition 4.2.6

FC03-C04-U021 · §4.2, pp. 122–125; L4103 · after FC03-C01-U028, FC03-C01-U049

Given a pair of functors \(F \colon \mathsf { C } \mathsf { D } \colon G ,\) , there exists a natural isomorphism \(\mathsf { D } ( F c , d ) \cong \mathsf { C } ( c , G d )\) if and only if there exists a pair of natural transformations \(\eta \colon 1 _ { \mathsf { C } } \Rightarrow G F\) and \(\epsilon \colon F G \Rightarrow { \mathrm { 1 } } _ { \mathsf { D } }\) satisfying the triangle identities.

Remark 4.2.7

FC03-C04-U022 · §4.2, pp. 122–125; L4127 · after FC03-C01-U028, FC03-C01-U049

Proposition 4.2.6 reveals that the data of a fully-specified adjunction can be presented in two equivalent forms: a pair of functors \(F \colon \mathsf{C} \to \mathsf{D}\), \(G \colon \mathsf{D} \to \mathsf{C}\) together with either (i) a natural family of isomorphisms \(\mathsf{D}(Fc,d) \cong \mathsf{C}(c,Gd)\) for all \(c \in \mathsf{C}\), \(d \in \mathsf{D}\), or, equivalently, (ii) natural transformations \(\eta \colon 1_{\mathsf{C}} \Rightarrow GF\) and \(\epsilon \colon FG \Rightarrow 1_{\mathsf{D}}\) satisfying \(G\epsilon \cdot \eta G = 1_{G}\) and \(\epsilon F \cdot F\eta = 1_{F}\). Definition 4.6.16

Let κ be a regular cardinal.12 A locally small category C is locally κ-presentable if it is cocomplete and if it has a set of objects S so that: (i) Every object in C can be written as a colimit of a diagram valued in the subcategory spanned by the objects in S . (ii) For each object \(s \in S\) , the functor \({ \mathsf { C } } ( s , - ) \colon { \mathsf { C } } \to\) Set preserves κ-filtered colimits. A functor between locally κ-presentable categories is accessible if it preserves κ-filtered colimits. For example, a large variety of categories whose objects are sets equipped with some sort of “algebraic” structure are locally finitely presentable (meaning locally ω-presentable); see Definition 5.5.5. A locally κ-presentable category is also locally λ-presentable for any \(\lambda > \kappa .\) Between locally presentable categories, meaning categories that are locally κ-presentable for some \(\kappa ,\) the adjoint functor theorem takes a part icularly appealing form, theorem 4.6.17: a functor between locally presentable categories admits a right adjoint if and only if it is cocontinuous, and a left adjoint if and only if it is continuous and accessible.
