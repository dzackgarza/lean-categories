### Theorem 4.6.17 {#fc03-c04-u076}

::: {.unit-meta}

A functor F : C D between locally presentable categories (i) admits a right adjoint if and only if it is cocontinuous. (ii) admits a left adjoint if and only if it is continuous and accessible.
