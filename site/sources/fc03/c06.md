`FC03-C06-U034` · §6.4, pp. 204–208; L6929 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

A point-set left derived functor is a homotopical LF:C→D with LF⇒F inducing the total left derived functor after localization; dually a point-set right derived functor is homotopical RF with F⇒RF inducing the total right derived functor.

### Definition 6.4.10 {#fc03-c06-u035}

::: {.unit-meta}
`FC03-C06-U035` · §6.4, pp. 204–208; L6941 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

• A left deformation on a homotopical category C consists of an endofunctor Q together with a natural weak equivalence $q \colon Q { \stackrel { \sim } { \Rightarrow } } 1 { \mathsf { c } }$ A left deformation for a functor $F \colon { \mathsf { C } } \to { \mathsf { D } }$ between homotopical categories consists of a left deformation $( Q , q )$ for $\complement$ such that $F$ preserves all weak equivalences between objects in a full subcategory containing the image of $Q .$ There is an obvious dual notion of right deformation $r \colon 1 \mathsf { c } \ { \stackrel { \sim } { \Rightarrow } } R$ Interestingly, left deformations can be used to construct point-set left derived functors, a homotopical universal property that is independent of the deformation used.

### Proposition 6.4.11 {#fc03-c06-u036}

::: {.unit-meta}
`FC03-C06-U036` · §6.4, pp. 204–208; L6951 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

If F:C→D has a left deformation q:Q⇒~1_C, then (LF=FQ, Fq:LF⇒F) is a point-set left derived functor; dually for right deformations.

### Proposition 6.4.12 {#fc03-c06-u037}

::: {.unit-meta}
`FC03-C06-U037` · §6.4, pp. 204–208; L6985 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)

The total left derived functor of a left deformable functor is an absolute right Kan extension, and in particular pointwise.

### Proposition 6.4.13 {#fc03-c06-u038}

::: {.unit-meta}
`FC03-C06-U038` · §6.4, pp. 204–208; L6993 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

Suppose $F \to G$ is an adjunction between homotopical categories and suppose also that F has a total left derived functor LF, G has a total right derived functor RG, and both derived functors are absolute Kan extensions. Then the total derived functors form an adjunction $\mathbf { L } F \lnot \ \mathbf { R } G$ between the homotopy categories.

### Proposition 6.5.1 {#fc03-c06-u040}

::: {.unit-meta}

The left Kan extension of F:C→D along the unique functor C→1 is exactly colim F, whenever either exists; dually the right Kan extension along C→1 is lim F.

### Proposition 6.5.2 {#fc03-c06-u041}

::: {.unit-meta}
`FC03-C06-U041` · §6.5, pp. 209–216; L7031 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

(i) $I f F \vdash G$ is an adjunction with unit η : $1 \Rightarrow G F$ and counit ǫ : $F G \Rightarrow 1$ , then $( G , \eta )$ is a left Kan extension of the identity functor along F and $( F , \epsilon )$ is a right Kan extension of the identity functor along G. Moreover, both Kan extensions are absolute, and in particular pointwise. (ii) Conversely, $i f ( G , \eta \colon 1 _ { \mathsf { C } } \Rightarrow G F )$ is a left Kan extension of the identity along F and if F preserves this Kan extension, then $F \to G$ with unit $\eta .$

### Example 6.5.11 {#fc03-c06-u047}

::: {.unit-meta}
`FC03-C06-U047` · §6.5, pp. 209–216; L7189 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

Consider the inclusion $\mathsf{Field} \hookrightarrow \mathsf{CRing}$. It has no left adjoint, because such a functor would carry $\mathbb{Z}$ to an initial field, which does not exist. But it does have a density monad $T$ defined by $$ TA := \prod_{\mathfrak{p} \in \operatorname{Spec}(A)} \operatorname{Frac}(A/\mathfrak{p}), $$ where $\operatorname{Spec}(A)$ is the set of prime ideals $\mathfrak{p} \subset A$ and $\operatorname{Frac}(A/\mathfrak{p})$ is the field of fractions of the integral domain $A/\mathfrak{p}$.

### Example 6.5.12 {#fc03-c06-u048}

::: {.unit-meta}

### Example 6.5.13 {#fc03-c06-u049}

::: {.unit-meta}
`FC03-C06-U049` · §6.5, pp. 209–216; L7207 · after [`FC03-C01-U028`](c01.html#fc03-c01-u028), [`FC03-C01-U049`](c01.html#fc03-c01-u049), [`FC03-C06-U002`](#fc03-c06-u002)
:::

The Giry monad of Example 5.1.5(iv) is also a codensity monad for the inclusion of a subcategory of ${ \mathsf { C } } \hookrightarrow$ Meas. The objects of C are the finite powers of the unit interval $I = [ 0 , 1 ] \subset \mathbb { R } .$ equipped with the Borel σ-algebra, plus the measurable space of sequences in I that converge to 0. The objects can be regarded as convex subspaces of Euclidean space, from which perspective the morphisms are defined to be all afine maps between these spaces. Omitting the space of sequences, the subcategory of finite powers of the interval and afine maps generates a variant of the Giry monad for finitely additive probability measures as its codensity monad. See [Ave16].
