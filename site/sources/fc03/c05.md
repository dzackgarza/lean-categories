### Remark 5.1.2 {#fc03-c05-u002}

::: {.unit-meta}
`FC03-C05-U002` · §5.1, pp. 154–157; L5243 · after [`FC03-C04-U001`](c04.html#fc03-c04-u001)
:::

A monad on $\mathsf{C}$ is precisely a monoid in the monoidal category $\mathsf{C}^{\mathsf{C}}$ of endofunctors of $\mathsf{C}$, where the binary functor $\mathsf{C}^{\mathsf{C}} \times \mathsf{C}^{\mathsf{C}} \to \mathsf{C}^{\mathsf{C}}$ is composition and the unit object is the identity endofunctor $1_{\mathsf{C}} \in \mathsf{C}^{\mathsf{C}}$. The category of endofunctors is a strict monoidal category, in which the coherence isomorphisms can be taken to be identities.

### Lemma 5.1.3 {#fc03-c05-u003}

::: {.unit-meta}
`FC03-C05-U003` · §5.1, pp. 154–157; L5257 · after [`FC03-C04-U001`](c04.html#fc03-c04-u001)

Any adjunction $F \dashv U \colon \mathsf{C} \rightleftarrows \mathsf{D}$, with $\eta \colon 1_{\mathsf{C}} \Rightarrow UF$ and $\epsilon \colon FU \Rightarrow 1_{\mathsf{D}}$, gives rise to a monad on the category $\mathsf{C}$ serving as the domain of the left adjoint: the endofunctor is $T := UF$, the unit $\eta \colon 1_{\mathsf{C}} \Rightarrow T$ is the unit of the adjunction, and the whiskered counit $U\epsilon F \colon UFUF \Rightarrow UF$ serves as the multiplication $\mu \colon T^{2} \Rightarrow T$.

### Example 5.1.4 {#fc03-c05-u004}

::: {.unit-meta}

The following monads come from familiar adjunctions. (i) The free-forgetful adjunction between pointed sets and sets of Example 4.1.10(i) induces a monad on $\mathsf{Set}$ whose endofunctor $(-)_{+} \colon \mathsf{Set} \to \mathsf{Set}$ adds a new disjoint point. The components of the unit are the inclusions $\eta_{A} \colon A \to A_{+}$; the components of the multiplication $\mu_{A} \colon (A_{+})_{+} \to A_{+}$ are the identity on the subset $A$ and send both new points of $(A_{+})_{+}$ to the new point of $A_{+}$. By Lemma 5.1.3, or by direct verification, the associativity and unit diagrams $$ \mu_{A} \cdot \mu_{A_{+}} = \mu_{A} \cdot (\mu_{A})_{+}, \qquad \mu_{A} \cdot \eta_{A_{+}} = 1_{A_{+}} = \mu_{A} \cdot (\eta_{A})_{+} $$ commute. This monad is called the maybe monad, for the reasons explained in Example 5.2.10(i). There is a similar monad on $\mathsf{Top}$, or on any category with coproducts, adjoining a copy of a fixed object.

A monad on a preorder $( \mathsf { P } , \leq )$ is given by an order-preserving function $T \colon \mathsf { P } \mathsf { P }$ that is so that $p \leq T p$ and $T ^ { 2 } p \leq T p$ . If P is a poset, so that isomorphic objects are equal, these two conditions imply that $T ^ { 2 } p = T p$ . An order-preserving function T so that $p \leq T p$ and $T ^ { 2 } p = T p$ is called a closure operator. Dually, a comonad on a poset category $( \mathsf { P } , \leq )$ defines a kernel operator: an order-preserving function K so that $K p \le p$ and $K p = K ^ { 2 } p$

Given a vector space $V$ over a field $k$, an affine space is a non-empty set $A$ together with a translation function $+ \colon V \times A \to A$ such that $\vec{0} + \mathbf{a} = \mathbf{a}$ for all $\mathbf{a} \in A$; $(\vec{v} + \vec{w}) + \mathbf{a} = \vec{v} + (\vec{w} + \mathbf{a})$ for all $\vec{v}, \vec{w} \in V$ and $\mathbf{a} \in A$; and, for each $\mathbf{a} \in A$, the function $- + \mathbf{a} \colon V \to A$ is a bijection.

Let $\mathsf{C}$ be a category with a monad $(T,\eta,\mu)$. The Eilenberg–Moore category for $T$, or category of $T$-algebras, is the category $\mathsf{C}^{T}$ whose objects are pairs $(A \in \mathsf{C},\ a \colon TA \to A)$ for which the diagrams (5.2.5) commute in $\mathsf{C}$, that is $$ a \cdot \eta_{A} = 1_{A} \qquad\text{and}\qquad a \cdot Ta = a \cdot \mu_{A}, $$ and whose morphisms $f \colon (A,a) \to (B,b)$ are the $T$-algebra homomorphisms: maps $f \colon A \to B$ in $\mathsf{C}$ for which $f \cdot a = b \cdot Tf$, with composition and identities as in $\mathsf{C}$.

For instance: (i) Consider the free pointed set monad of Example 5.1.4(i). An algebra is a set A with a map a : $A _ { + } \to A$ so that the diagrams (5.2.5) commute. The square imposes no additional conditions, but the triangle asserts that the map a : $A _ { + } \to A$ restricts to the identity on the A component of the disjoint union $A _ { + } = A \sqcup { * }$ . Thus, the data of an algebra is a set with a specified basepoint $a \in A$ , the image of the extra point under the map a : $A _ { + } \to A$ . A morphism $f \colon ( A , a ) ( B , b )$ is a map f : A B so that $$ \begin{array}{c} A _ {+} \xrightarrow {f _ {+}} B _ {+} \ \Biggl \downarrow a \ A \xrightarrow {f} B \end{array} $$ commutes. The map $f _ { + }$ carries the extra point in $A .$ + to the extra point in $B _ { + }$ , so this condition demands that $f ( a ) = b$ . In conclusion, the Eilenberg–Moore category is isomorphic to $\mathtt { S e t } _ { * }$ , the ca tegory of pointed sets.
