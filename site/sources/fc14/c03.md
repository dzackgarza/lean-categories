### Definition: reflection and Cartan pairing notation {#fc14-c03-u002}

`FC14-C03-U002` · §9.1; p. 42 · after [`FC14-C03-U001`](#fc14-c03-u001)

### Lemma: recognition of a root reflection {#fc14-c03-u003}

::: {.unit-meta}

### Definition: root system {#fc14-c03-u004}

::: {.unit-meta}
`FC14-C03-U004` · §9.2; pp. 42–43 · after [`FC14-C03-U002`](#fc14-c03-u002)
:::

A root system Φ⊂E is finite, spans E, excludes 0, contains only ±α on each root line, is invariant under every σ_α, and satisfies ⟨β,α⟩∈Z for all α,β∈Φ.

### Definition: Weyl group {#fc14-c03-u005}

::: {.unit-meta}
`FC14-C03-U005` · §9.2; p. 43 · after [`FC14-C03-U004`](#fc14-c03-u004)
:::

`FC14-C03-U062` · §13.4; p. 70 · after [`FC14-C03-U055`](#fc14-c03-u055)
:::

A subset Π⊆Λ is saturated if λ∈Π and 0≤i≤⟨λ,α⟩ imply λ−iα∈Π. It is W-stable. A saturated Π has highest weight λ∈Λ⁺ if every μ∈Π satisfies μ≤λ.

### Lemma: finite saturated sets with highest weight {#fc14-c03-u063}

::: {.unit-meta}
`FC14-C03-U063` · §13.4; p. 70 · after [`FC14-C03-U059`](#fc14-c03-u059), [`FC14-C03-U062`](#fc14-c03-u062)
:::

Every saturated set of weights with a highest weight is finite.

### Lemma: all lower dominant weights occur in a saturated set {#fc14-c03-u064}

::: {.unit-meta}
`FC14-C03-U064` · §13.4; pp. 70–71 · after [`FC14-C03-U062`](#fc14-c03-u062)
:::

If Π is saturated with highest weight λ and μ is dominant with μ≤λ, then μ∈Π.

### Theorem: characterization of saturated sets by dominant weights {#fc14-c03-u065}

::: {.unit-meta}
`FC14-C03-U065` · §13.4; p. 71 · after [`FC14-C03-U058`](#fc14-c03-u058), [`FC14-C03-U064`](#fc14-c03-u064)
:::

A saturated set with highest weight λ consists exactly of the dominant weights μ≤λ together with all their W-conjugates; conversely this prescription yields the unique saturated set of highest weight λ.

### Lemma: highest-weight norm inequality for saturated sets {#fc14-c03-u066}

::: {.unit-meta}

If Π is saturated with highest weight λ and μ∈Π, then (μ+δ,μ+δ)≤(λ+δ,λ+δ), with equality only for μ=λ.
